## N-Gram模型

什么是Gram? Gram就是一个单词。
N-Gram就是N个单词。

N-Gram模型，就是把句子分成N个单词，然后统计每个单词出现的次数，常用的就是2-gram和3-gram。

2-gram就是两个单词为一组，最终用前一个单词预测后一个单词

3-gram就是三个单词为一组，最终用前两个单词预测第三个单词

```python
from collections import defaultdict

# 构建一个预测模型 {context: {next_word: count}}
# defaultdict(lambda: defaultdict(int))表示创建一个字典，字典的value是一个字典
model = defaultdict(lambda: defaultdict(int))
for i in range(len(words) - n + 1):
    context = tuple(words[i:i + n - 1])  # 前n-1个词作为上下文
    next_word = words[i + n - 1]  # 预测目标词
    model[context][next_word] += 1

model
```

```python
# 定义一个预测函数
def predict_next_word(model, context):
    # 根据上下文预测概率最高的词
    context = tuple(context)
    if context not in model:
        return None  # 上下文不存在于模型中
    next_words = model[context]

    # 返回概率最高的词 items会将dict转成kv的元组
    return max(next_words.items(), key=lambda x: x[1])[0]
```

N-Gram模型的优点是计算简单、速度快，缺点是无法捕捉距离较远的两个词之间的关系。

核心思想是：每次根据前面的两个词来预测下一个词，从而忽视了之前的很多词。
