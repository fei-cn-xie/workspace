```python
        x = torch.relu(self.fc2(x))  # (16, 128) * (128, 256) = (16, 256)
        x = torch.relu(self.fc3(x))  # (16, 256) * (256, 128) = (16, 128)
        x = self.fc4(x)  # (16, 128) * (128, 1) = (16, 1)
        return x
```

因为上面的模型本质上是一个线性模型，不适合分类任务，我们需要定义好模型的输出固定只有10个类别，因此我们修改最后一层为10个神经元，并且使用交叉熵损失函数

```python
from torch import nn
import torch


class MnistModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(1 * 28 * 28, 128)
        self.fc2 = nn.Linear(128, 256)
        self.fc3 = nn.Linear(256, 128)
        self.fc4 = nn.Linear(128, 10)  # img--->(r0,r1,r2....r9) 数值 分类

    def forward(self, x):
        x = torch.relu(self.fc1(x))  # (16, 1*28*28) * (1*28*28, 128) = (16, 128)
        x = torch.relu(self.fc2(x))  # (16, 128) * (128, 256) = (16, 256)
        x = torch.relu(self.fc3(x))  # (16, 256) * (256, 128) = (16, 128)
        x = self.fc4(x)  # (16, 128) * (128, 1) = (16, 10)
        return x
```

## 交叉熵CrossEntropy

x-->手写体数字图片--->数值不确定，预测值0.9， 真实值1 (0.999999-1)**2=0.01误差, 精确 0-9, 离散

x-->手写体数字图片---->[0.1, 0.9, 2.1, 2.4, 5.5, 7.3, 0.4, 3.1, 1.2, 2.2]--->5

MES和CrossEntropy都是计算误差的方式，MSE适合回归任务，而CrossEntropy适合分类任务。

假如，x是一张手写体数字图片，模型对应的预测值为0.9，但是真实值为1，那么MSE算出来的误差为：(0.9-1)**2=0.01，误差其实很小了，但是如果模型到此为止就还不行，因为如果拿这个模型预测，输入一张图片，它的预测结果为0.9，而图片中根本就是没有0.9这个数字，那么预测其实还是错的，这就要求模型要把误差0.01降到0，这就要求非常精确，很难做到，而对于回归任务，0.9和1其实差别不大，如果是回归任务，比如房价预测，预测结果为0.9，而真实值是1，其实是可以接受的。

而交叉熵计算误差的方式是这样的：x是一张手写体数字图片，模型会输出10个预测值，每个预测值对应一个0-9数字，相当于10个类别，而预测值越大，我们就认为x越接近于对应的数字，比如模型的预测结果为[0.1, 0.9, 2.1, 2.4, 5.5, 7.3, 0.4, 3.1, 1.2, 2.2]，这其中7.3这个数值最大，它对应的下标为5，所以我们任务x对应的是数字5，那么如何计算误差呢？

我们先把以上数值转成概率，这里用到softmax，softmax的结果为：[6.1957e-04, 1.3789e-03, 4.5780e-03, 6.1797e-03, 1.3718e-01, 8.2987e-01, 8.3633e-04, 1.2444e-02, 1.8613e-03, 5.0595e-03]，这就是x对应0-9的概率分布，这些概率加起来是1，也就是不会出现40%是1，,40%是2，40%是3这种总概率超过1的情况，而这其中8.2987e-01是最大的，表示大概80%的概率是5，其他几个数也有一定概率，但是概率比较小。

此时，如果真实值确实就是5，那么表示预测对了，经过概率大概是80%，但模型其实没有必要一定要把这个概率提高到100%。

那如果真实值不是5，比如真实值是6，那么表示预测错了，此时就可以算误差了，是这么算的-np.log(8.3633e-04)

```python
loss = -np.log(8.3633e-04)
print(loss)
```

## softmax

在上面的模型中，最后一层是10个神经元，每个神经元的输出是一个数字，这个数字越大，表示对应类别的概率就越高

softmax的函数定义
$softmax(x)_i = \frac{e^{x_i}}{\sum_{j=1}^{n}e^{x_j}}$

softmax的作用是：将向量中的每个元素变成概率，使其和为1

为什么需要softmax呢？

```python
class MnistModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(1 * 28 * 28, 128)  # fulll connection
        self.fc2 = nn.Linear(128, 128)
        self.fc3 = nn.Linear(128, 128)
        self.fc4 = nn.Linear(128, 10)  # img--->(r0,r1,r2....r9) 数值 分类
        self.dropout = nn.Dropout(0.1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))  # (16, 1*28*28) * (1*28*28, 128) = (16, 128)
        x = self.dropout(x)
        # x = torch.relu(self.fc2(x))  # (16, 128) * (128, 256) = (16, 256)
        # x = self.dropout(x)
        # x = torch.relu(self.fc3(x))  # (16, 256) * (256, 128) = (16, 128)
        # x = self.dropout(x)
        x = self.fc4(x)  # (16, 128) * (128, 1) = (16, 10)
        return x


model = MnistModel()

optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
criterion = nn.CrossEntropyLoss()
writer = SummaryWriter()

epochs = 100
model.train() # train=false dropout
total_train_loss = 0.0
for epoch in range(epochs):
    for i, (images, labels) in enumerate(train_loader):

        outputs = model(images.view(-1, 1 * 28 * 28))
        loss = criterion(outputs, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_train_loss += loss.item()

        # 每100步记录一次训练损失 step
        if (i + 1) % 10 == 0:
            avg_train_loss = total_train_loss / 10
            total_train_loss = 0.0

            # 评估
            model.eval()
            total_valid_loss = 0.0
            with torch.no_grad():
                for valid_images, valid_labels in valid_loader:
                    valid_outputs = model(valid_images.view(-1, 1 * 28 * 28))
                    valid_loss = criterion(valid_outputs, valid_labels)
                    total_valid_loss += valid_loss.item()
            avg_valid_loss = total_valid_loss / len(valid_loader)

            print('Epoch [{}/{}], Step [{}/{}], training loss: {:.4f}, validation loss: {:.4f}'
                  .format(epoch + 1, epochs, i + 1, len(train_loader), avg_train_loss, avg_valid_loss))

            global_step = epoch * len(train_loader) + i
            writer.add_scalar('training loss', avg_train_loss, global_step)
            writer.add_scalar('validation loss', avg_valid_loss, global_step)
```

## 评估集、过拟合、欠拟合、Dropout

Dropout是神经网络中的一种正则化方法，它可以防止过拟合，在训练过程中，每次前向传播时，都强制让20%的神经元“休息” (输出值设为0)，强迫剩下的神经元更努力地协作，学习更稳健、更通用的特征模式，最终效果是让你的模型不那么容易死记硬背训练数据 (减少过拟合)，提高在没见过的数据上的表现 (泛化能力)。
