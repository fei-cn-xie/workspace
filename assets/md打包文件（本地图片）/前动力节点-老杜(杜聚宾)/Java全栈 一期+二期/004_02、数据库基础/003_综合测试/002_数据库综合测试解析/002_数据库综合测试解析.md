## 第一部分：选择题答案及解析

### 1. 关于MySQL事务的ACID特性，以下描述错误的是：

**答案：D**
**解析：** 持久性确保事务提交后，对数据库的修改是永久的，但并不是"立即永久保存到磁盘"。MySQL使用缓冲池和日志机制来保证持久性，数据可能先写入内存和redo log，然后异步刷盘。

### 2. 在MySQL中，关于索引的说法正确的是：

**答案：D**
**解析：**

- A错误：主键索引要求唯一且非空，唯一索引允许空值
- B错误：联合索引字段顺序影响查询性能，遵循最左前缀原则
- C错误：不合理的索引可能降低性能（如小表全表扫描更快）
- D正确：LIKE '%keyword'前导通配符无法使用索引

### 3. 关于数据库三范式，以下描述正确的是：

**答案：D**
**解析：** 三范式的要求分别是：

- 第一范式：字段原子性
- 第二范式：非主键字段完全依赖于主键
- 第三范式：消除传递依赖

### 4. 在JDBC中，PreparedStatement相比Statement的主要优势不包括：

**答案：D**
**解析：** PreparedStatement的优势包括防止SQL注入、提高执行效率（预编译）、支持批量操作，但不会简化SQL语句编写。

### 5. 关于数据库连接池，以下说法错误的是：

**答案：D**
**解析：** 连接池必须考虑并发问题，多个线程同时获取连接时需要保证线程安全。

### 6. 关于数据库连接池，以下哪个配置可能导致连接泄露？

**答案：D**
**解析：** `testWhileIdle=false`可能导致无效连接不被检测，结合较长的`maxWait`时间，可能产生连接泄露。其他选项都有助于连接管理和泄露预防。

### 7. 关于InnoDB的行级锁，以下说法正确的是：

**答案：D**
**解析：**

- A正确：InnoDB行锁基于索引实现
- B正确：无索引时升级为表锁
- C正确：间隙锁在REPEATABLE-READ级别下防止幻读

### 8. 关于MySQL的REPEATABLE-READ隔离级别，以下说法错误的是：

**答案：D**
**解析：** REPEATABLE-READ不能完全解决幻读问题，在某些情况下（如范围更新）仍可能出现幻读。

### 9. 在JDBC编程中，关于ResultSet的处理，以下哪种做法是错误的：

**答案：D**
**解析：** 在遍历ResultSet时使用同一个Statement执行新查询会导致前一个ResultSet被关闭，这是错误的做法。

### 10. 关于MySQL的MVCC机制，以下说法错误的是：

**答案：D**
**解析：** MVCC减少了锁竞争，但不能完全避免所有锁竞争，写操作仍然需要加锁。

    product_id INT PRIMARY KEY AUTO_INCREMENT,

    price DECIMAL(10,2) NOT NULL CHECK(price >= 0),
    stock INT NOT NULL CHECK(stock >= 0) DEFAULT 0,
    list_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP

-- 订单表
CREATE TABLE orders (
    order_id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    order_amount DECIMAL(10,2) NOT NULL CHECK(order_amount >= 0),
    order_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    order_status VARCHAR(20) NOT NULL DEFAULT 'pending',
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);

-- 订单明细表
CREATE TABLE order_items (
    item_id INT PRIMARY KEY AUTO_INCREMENT,
    order_id INT NOT NULL,
    product_id INT NOT NULL,
    quantity INT NOT NULL CHECK(quantity > 0),
    unit_price DECIMAL(10,2) NOT NULL CHECK(unit_price >= 0),
    FOREIGN KEY (order_id) REFERENCES orders(order_id),
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

### SQL查询题答案

**1. 查询2023年每个月的订单总金额**

```sql
SELECT 
    YEAR(order_time) as year,
    MONTH(order_time) as month,
    SUM(order_amount) as total_amount
FROM orders 
WHERE YEAR(order_time) = 2023
GROUP BY YEAR(order_time), MONTH(order_time)
ORDER BY year, month;
```

**2. 查询购买金额前5名的用户信息**

```sql
SELECT 
    u.username,
    SUM(o.order_amount) as total_purchase
FROM users u
JOIN orders o ON u.user_id = o.user_id
GROUP BY u.user_id, u.username
ORDER BY total_purchase DESC
LIMIT 5;
```

**3. 查询从未下过单的用户列表**

```sql
SELECT 
    user_id,
    username,
    email
FROM users
WHERE user_id NOT IN (SELECT DISTINCT user_id FROM orders);
```

**4. 查询库存紧张且近30天没有销售记录的商品**

```sql
SELECT 
    p.product_id,
    p.product_name,
    p.stock,
    p.price
FROM products p
WHERE p.stock < 10
AND p.product_id NOT IN (
    SELECT DISTINCT oi.product_id
    FROM order_items oi
    JOIN orders o ON oi.order_id = o.order_id
    WHERE o.order_time >= DATE_SUB(CURRENT_DATE, INTERVAL 30 DAY)
);
```

public boolean processPurchase(int userId, int productId, int quantity) {
    String checkStockSql = "SELECT stock, price FROM products WHERE product_id = ? FOR UPDATE";
    String updateStockSql = "UPDATE products SET stock = stock - ? WHERE product_id = ? AND stock >= ?";
    String insertOrderSql = "INSERT INTO orders (user_id, order_amount, order_status) VALUES (?, ?, 'completed')";
    String insertOrderItemSql = "INSERT INTO order_items (order_id, product_id, quantity, unit_price) VALUES (?, ?, ?, ?)";
    
    try (Connection conn = dataSource.getConnection()) {
        conn.setAutoCommit(false);
        
        try {
            // 1. 检查库存和价格
            double productPrice;
            int currentStock;
            
            try (PreparedStatement checkStmt = conn.prepareStatement(checkStockSql)) {
                checkStmt.setInt(1, productId);
                try (ResultSet rs = checkStmt.executeQuery()) {
                    if (rs.next()) {
                        currentStock = rs.getInt("stock");
                        productPrice = rs.getDouble("price");
                    } else {
                        throw new SQLException("商品不存在");
                    }
                }
            }
            
            if (currentStock < quantity) {
                throw new SQLException("库存不足");
            }
            
            // 2. 更新库存
            try (PreparedStatement updateStmt = conn.prepareStatement(updateStockSql)) {
                updateStmt.setInt(1, quantity);
                updateStmt.setInt(2, productId);
                updateStmt.setInt(3, quantity);
                
                if (updateStmt.executeUpdate() == 0) {
                    throw new SQLException("库存更新失败");
                }
            }
            
            // 3. 创建订单
            int orderId;
            try (PreparedStatement orderStmt = conn.prepareStatement(insertOrderSql, Statement.RETURN_GENERATED_KEYS)) {
                orderStmt.setInt(1, userId);
                orderStmt.setDouble(2, productPrice * quantity);
                
                if (orderStmt.executeUpdate() > 0) {
                    try (ResultSet generatedKeys = orderStmt.getGeneratedKeys()) {
                        if (generatedKeys.next()) {
                            orderId = generatedKeys.getInt(1);
                        } else {
                            throw new SQLException("获取订单ID失败");
                        }
                    }
                } else {
                    throw new SQLException("订单创建失败");
                }
            }
            
            // 4. 创建订单明细
            try (PreparedStatement itemStmt = conn.prepareStatement(insertOrderItemSql)) {
                itemStmt.setInt(1, orderId);
                itemStmt.setInt(2, productId);
                itemStmt.setInt(3, quantity);
                itemStmt.setDouble(4, productPrice);
                
                if (itemStmt.executeUpdate() == 0) {
                    throw new SQLException("订单明细创建失败");
                }
            }
            
            // 提交事务
            conn.commit();
            return true;
            
        } catch (SQLException e) {
            conn.rollback();
            System.out.println("事务回滚: " + e.getMessage());
            return false;
        }
        
    } catch (SQLException e) {
        e.printStackTrace();
        return false;
    }
}

### JDBC高级编程（15分）

```java
public int batchUpdateStock(Map<Integer, Integer> productUpdates) throws SQLException {
    int successCount = 0;
    Connection conn = null;
    
    try {
        conn = DriverManager.getConnection(url, username, password);
        conn.setAutoCommit(false);
        
        // 检查库存是否充足
        String checkSql = "SELECT product_id, stock FROM products WHERE product_id = ? FOR UPDATE";
        String updateSql = "UPDATE products SET stock = stock + ? WHERE product_id = ?";
        
        try (PreparedStatement checkStmt = conn.prepareStatement(checkSql);
             PreparedStatement updateStmt = conn.prepareStatement(updateSql)) {
            
            // 检查所有商品的库存是否充足
            for (Map.Entry<Integer, Integer> entry : productUpdates.entrySet()) {
                int productId = entry.getKey();
                int change = entry.getValue();
                
                if (change < 0) { // 出库操作需要检查库存
                    checkStmt.setInt(1, productId);
                    try (ResultSet rs = checkStmt.executeQuery()) {
                        if (rs.next()) {
                            int currentStock = rs.getInt("stock");
                            if (currentStock + change < 0) {
                                throw new SQLException("商品ID " + productId + " 库存不足");
                            }
                        } else {
                            throw new SQLException("商品ID " + productId + " 不存在");
                        }
                    }
                    checkStmt.clearParameters();
                }
            }
            
            // 执行批量更新
            for (Map.Entry<Integer, Integer> entry : productUpdates.entrySet()) {
                int productId = entry.getKey();
                int change = entry.getValue();
                
                updateStmt.setInt(1, change);
                updateStmt.setInt(2, productId);
                updateStmt.addBatch();
            }
            
            int[] updateResults = updateStmt.executeBatch();
            successCount = updateResults.length;
            
            conn.commit();
            
        } catch (SQLException e) {
            if (conn != null) {
                conn.rollback();
            }
            throw e;
        }
        
    } finally {
        if (conn != null) {
            try {
                conn.setAutoCommit(true);
                conn.close();
            } catch (SQLException e) {
                e.printStackTrace();
            }
        }
    }
    
    return successCount;

}
```

**解析要点：**

1. 使用事务确保所有更新操作原子性
2. 使用批量操作提高性能
3. 出库前检查库存充足性
4. 使用FOR UPDATE锁定记录防止并发问题
5. 合理的异常处理和资源管理
