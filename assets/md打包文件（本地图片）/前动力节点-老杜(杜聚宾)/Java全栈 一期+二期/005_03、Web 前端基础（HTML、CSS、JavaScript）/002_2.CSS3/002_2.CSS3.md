# CSS的简介

## 什么是CSS

CSS（层叠样式表，Cascading Style Sheets）是一种用于控制网页外观和布局的标记语言，专门为HTML（或XML等结构化文档）设计。它的核心作用是将网页的内容（HTML）与样式（如颜色、字体、间距等）分离，让开发者更高效地管理网页的视觉效果。

CSS是前端开发的三大基石之一（HTML+CSS+JavaScript），负责将枯燥的HTML页面变成视觉美观、布局合理的网页。现代CSS还支持动画、变量（CSS Variables）等高级功能，是构建用户友好界面的关键工具。

## CSS主要功能

1. 美化页面
  1. 控制文字颜色、字体、大小、对齐方式。
  2. 设置背景颜色、图片、渐变效果。
  3. 调整元素间距（内边距、外边距）、边框样式。
2. 布局设计
  1. 实现多栏布局、响应式设计（适配不同设备屏幕）。
  2. 定位元素（固定、浮动、绝对定位等）。
  3. 使用Flexbox或Grid系统创建复杂排版。
3. 交互增强
  1. 定义鼠标悬停（:hover）、点击等状态的样式。
  2. 配合JavaScript实现动画或动态效果（如过渡、变换）。

## CSS的优势

- 结构与样式分离：修改外观无需改动HTML代码。
- 复用性强：一套样式可应用于多个页面或元素。
- 响应式设计：适配手机、平板等设备。

## 引入样式方式

### 内联样式

```html
<p style="color: red; font-size: 14px">我是一个p标签</p>
```

### 内部样式

```css
<style>
    body {
        /*设置背景颜色*/
        background-color: yellow;
    }

    h1 {
        /*设置字体颜色*/
        color: blue;
        /*设置字体大小*/
        font-size: 30px;
    }
</style>
```

注意：CSS中的注释写法

### 外部样式

实现步骤：

第一步：编写单独的css文件，例如`index.css`

```css
body {
    /*设置背景颜色*/
    background-color: yellow;
}

h1 {
    /*设置字体颜色*/
    color: blue;
    /*设置字体大小*/
    font-size: 30px;
}
```

第二步：在需要引入css文件的html文档中使用`<link>`引入

```html
<head>
    <meta charset="UTF-8">
    <title>CSS层叠样式表</title>
    <!--引入外部的层叠样式表，href指向的是需要加载样式表的.css文件-->
    <link rel="stylesheet" href="css/index.css">
</head>
```

将CSS代码单独保存在 **.css文件** 中，再通过HTML的 `<link>` 标签引入（而非直接写在HTML内），是前端开发的最佳实践之一。这样做的主要好处如下：

1. **结构与样式分离（可维护性高）**

- **修改方便**：只需修改单个`.css`文件即可全局更新所有页面的样式，无需逐个修改HTML文件。
*例如：更改网站主题色时，只需调整CSS中的颜色变量，所有页面自动同步。*
- **代码更清晰**：HTML专注内容结构，CSS专注视觉效果，分工明确，便于团队协作。

1. **复用性强（减少冗余代码）**

- **多页面共享样式**：多个HTML页面可以引用同一个CSS文件，避免重复编写样式代码。
*例如：网站的所有页面共用*`styles.css`*，保持整体风格一致。*
- **模块化管理**：可按功能拆分多个CSS文件（如`layout.css`、`theme.css`），按需引入。

1. **提高加载性能**

- **浏览器缓存优化**：CSS文件会被浏览器缓存，用户访问同一网站的多个页面时无需重复下载，加快加载速度。
*对比：内联CSS（写在HTML中）每次访问页面都需重新加载。*
- **减少代码体积**：复用样式减少了HTML文件的体积，尤其对大型项目更明显。

通过`<link>`引入外部CSS文件是**可维护性、性能、复用性**的最佳平衡方案，尤其适合中大型项目。只有极少数特殊情况（如关键首屏样式）才会考虑内联CSS。

## 长度单位

| **单位** | **描述** |
| --- | --- |
| px | 像素 (计算机屏幕上的一个点) |
| em | 相对于当前元素内文本的字体尺寸，1em 等于当前元素所采用的字体尺寸值。 这个尺寸基准来源于元素自身设置的 `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">font-size</font>`；如果当前元素没有显式设置字体尺寸，则会继承其父元素的字体尺寸。 |
| % | 相对于父元素高度或宽度的百分比 |

```html
    width: 5em;
  }
  
  .child {
    background-color: rgb(230, 243, 116);
    width: 10em;
  }
  
</style>
</head>
<body>

<div class="parent">
  父节点
  <div class="child">
    子节点
  </div>
</div>

</body>
</html>
```

## 颜色单位

颜色是通过对 `红(red)、绿(green)、蓝(blue)`色的组合来显示的。

1. RGB 颜色值是这样规定的：rgb(red, green, blue)，每个参数定义颜色的强度，可以是介于 0 与 255 之间的整数，或者是百分比值（从 0% 到 100%）。
2. 十六进制颜色是这样规定的：#RRGGBB，其中的 RR（红色）、GG（绿色）、BB（蓝色）十六进制整数规定了颜色的成分。所有值必须介于00 到 FF（255的十六进制是 FF） 之间。另外十六进制方式是可以简写的，可简写为：#RGB

## 相对路径与绝对路径

在Web开发中，**路径（Path）** 用于定位外部资源（如图片、CSS文件、JavaScript文件等）。路径分为 **相对路径** 和 **绝对路径**，它们的核心区别在于 **参照点的不同**。以下是详细解释：

### 相对路径（Relative Path）

**以当前文件所在位置为参照**，通过层级关系指向目标文件。

#### 常见语法

| **符号** | **说明** |
| --- | --- |
| `file.txt` | 目标文件与当前文件**同级**，直接写文件名。 |
| `./file.txt` | `./` 表示当前目录（可省略，效果同上）。 |
| `../file.txt` | `../` 表示**上一级目录**，每多一个`../`就再往上一层。 |
| `images/photo.jpg` | 进入当前目录下的`images`文件夹，找`photo.jpg`。 |

#### 示例场景

假设项目结构如下：

```plaintext
project/
  ├── index.html
  ├── css/
  │    └── style.css
  └── images/
       ├── logo.png
       └── bg/
            └── background.jpg
```

**在 **`index.html`** 中引用资源**

```html
<!-- 引入同级css文件夹中的style.css -->
<link rel="stylesheet" href="css/style.css">

<!-- 引入images文件夹下的logo.png -->
<img src="images/logo.png">

<!-- 引入images/bg/下的background.jpg -->
<img src="images/bg/background.jpg">
```

**在 **`style.css`** 中引用图片**

```css
body {
  /* 从css文件出发，需先返回上级目录（../），再进入images */
  background-image: url("../images/bg/background.jpg");
}
```

### 绝对路径（Absolute Path）

**从根目录（或完整URL）出发**，直接指向目标文件的完整路径。

#### 两种形式

1. **基于网站根目录的绝对路径**
  - 以 `/` 开头，表示从网站的根目录（通常是域名对应的文件夹）开始查找。
  - *示例*：

```html
<!-- 无论当前文件在哪，都从根目录开始找 -->
<img src="/images/logo.png">
<link rel="stylesheet" href="/css/style.css">
```

1. **完整URL的绝对路径**
  - 直接使用完整的HTTP/HTTPS地址（常用于引用外部资源）。
  - *示例*：

```html
<img src="https://example.com/images/logo.png">
<link rel="stylesheet" href="https://cdn.example.com/style.css">
```

#### 示例场景

```plaintext
project/（网站根目录）
  ├── index.html
  └── assets/
       ├── css/
       │    └── style.css
       └── images/
            └── logo.png
```

```html
<!-- 从根目录开始找 -->
<img src="/assets/images/logo.png">
<link rel="stylesheet" href="/assets/css/style.css">
```

# CSS选择器

CSS选择器主要包括：

1. 基础选择器
2. 关系选择器
3. 属性选择器
4. 伪类选择器
5. 通配符选择器

## 基础选择器

基础选择器包含：

1. 标签选择器
2. class选择器
3. id选择器

### 标签选择器

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        p {
            color: blue;
            font-size: 18px;
            background-color: yellow;
        }
    </style>
</head>
<body>
    <p>我是第一个p标签</p>
    <p>我是第二个p标签</p>
    <p>我是第三个p标签</p>
</body>
</html>
```

直接以`标签名`作为选择器，以上代码的含义是：页面中所有的`p`标签将全部使用该样式。

### 类选择器

第一步：给需要选中的元素添加class属性。

第二步：选中该元素再添加样式 `.类名 { 属性: 值; }`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS层叠样式表</title>
    <style>
        .tag {
            color: blue;
        }
    </style>
</head>
<body>
    <h1 class="tag">我是标题</h1>
    <div class="tag">我是一个div</div>
</body>
</html>
```

可以看到类选择器可以将样式应用在不同的标签上。

### id选择器

第一步：给需要选中的元素添加id属性

第二步：选中该元素添加样式 `#id { 属性: 值; }`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        #title {
            color: blue;
        }
        #block {
            /*文字居中*/
            text-align: center;
            color: red;
        }
    </style>
</head>
<body>
    <h1 id="title">我是标题</h1>
    <div id="block">我是一个div</div>
</body>
</html>
```

## 关系选择器

### 交集选择器

CSS交集选择器是由两个选择器紧密连接组成的（中间没有空格），它用于选中同时满足两个条件的元素。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        /*选中"我是一个div标签"的这个标签*/
        div.tag {
            color: blue;
        }
        /*选中"我是一个p标签"的这个标签*/
        p#title {
            font-size: 30px;
        }
    </style>
</head>
<body>
    <h1 class="tag">我是标题</h1>
    <div class="tag">我是一个div标签</div>
    <p id="title">我是一个p标签</p>
</body>
</html>
```

### 并集选择器

并集选择器是由多个选择器通过逗号`,`连接在一起的，这些选择器分别是：标签选择器、类选择器或id选择器等。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        /*选中符合条件的所有标签*/
        .search, span, #Important {
            color: red;
        }
    </style>
</head>
<body>
    <a class="search" href="#">百度一下</a>
    <h1>我是一个h1标签</h1>
    <span>我是一个span标签</span>
    <div>
        <p>我是一个p标签</p>
        <span>我是一个span标签</span>
        <strong id="Important">我是一个强调标签</strong>
    </div>
    <p>我是一个p标签</p>
</body>
</html>
```

### 后代选择器

后代选择器又称为包含选择器，选择所有被`E元素`包含的`F元素`，中间用`空格`隔开。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        /*选中所有.box标签中存在的span标签*/
        .box span {
            color: red;
        }
    </style>
</head>
<body>
    <div class="box">
        <h1>我是一个h1标签</h1>
        <span>我是一个span标签</span>
        <div>
            <p>我是一个p标签</p>
            <span>我是一个span标签</span>
            <strong>我是一个强调标签</strong>
        </div>
        <p>我是一个p标签</p>
    </div>
</body>
</html>
```

### 亲子选择器

选择所有作为`E元素`的直接`子元素F`，对`孙子元素`不起作用，用`大于号`表示。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器</title>
    <style>
        .tag > span {
            color: red;
        }
    </style>
</head>
<body>
    <div class="tag">
        <h1>我是一个h1标签</h1>
        <span>我是一个span标签</span>
        <div>
            <p>我是一个p标签</p>
            <span>我是一个span标签</span>
            <strong>我是一个强调标签</strong>
        </div>
        <p>我是一个p标签</p>
    </div>
</body>
</html>
```

请看下面这个效果就有点意思了：

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>css的亲子选择器</title>
  <style>
    .tag > span{
      color: red;
      font-size: 30px;
      font-weight: bold;
    }
  </style>
</head>
<body>
  <div class="tag">
    <span>spanA
      <span>spanA1</span>
    </span>
    <span>spanB</span>
  </div>
</body>
</html>
```

以上代码渲染之后：`spanA1`为什么也有样式？不是亲子选择器吗？不是应该只作用于 `spanA`元素吗？

这个原因是因为某些样式是支持继承，以上亲子选择器确实只作用于直接 span 子元素。只不过 `spanA1`将 `spanA`的样式继承过来了。在 CSS 中都有哪些样式是可以继承的呢？

**会继承的样式（常用）**

**文本相关**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">color</font>` - 文字颜色
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">font-family</font>` - 字体
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">font-size</font>` - 字体大小
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">font-weight</font>` - 字体粗细
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">font-style</font>` - 字体样式（斜体等）
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">line-height</font>` - 行高
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">text-align</font>` - 文本对齐
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">text-indent</font>` - 首行缩进
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">letter-spacing</font>` - 字母间距
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">word-spacing</font>` - 单词间距
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">text-transform</font>` - 文本转换（大小写）

**列表相关**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">list-style-type</font>` - 列表标记类型
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">list-style-position</font>` - 列表标记位置

**其他**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">visibility</font>` - 可见性
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">cursor</font>` - 鼠标光标

**不会继承的样式（常用）**

**盒模型相关**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">width</font>` / `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">height</font>` - 宽高
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">margin</font>` - 外边距
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">padding</font>` - 内边距
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">border</font>` - 边框
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">background</font>` - 背景
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">display</font>` - 显示方式

**定位相关**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">position</font>` - 定位方式
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top</font>` / `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right</font>` / `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">bottom</font>` / `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>` - 定位位置
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">float</font>` - 浮动
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">clear</font>` - 清除浮动

**其他**

- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">overflow</font>` - 溢出处理
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">z-index</font>` - 层级
- `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">opacity</font>` - 透明度

## 通配符选择器

在 CSS 中，**通配符选择器** 主要用于匹配具有特定模式的元素名称、属性或属性值。以下是常见的通配符及其用法：

### 通用选择器

- **作用**：匹配页面中 **所有元素**（包括 `<html>`、`<body>` 及其子元素）。
- **示例**：

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

```plaintext
- **用途**：常用于全局重置样式（但性能较差，慎用）。
```

- 我来解释一下上面这个样式表示的含义

```css
* {
  /* 清除 body 元素的默认外边距 */
  /* 浏览器通常给 <body> 设置约 8px 的默认 margin，这会导致页面内容不贴边 */
  margin: 0;
  /* 清除 body 元素的默认内边距，确保 body 内部元素从最边缘开始布局 */
  padding: 0;
  /* 改变盒模型计算方式 */
  /* 默认是 content-box：元素的宽度 = 内容宽度 + padding + border */
  /* 改为 border-box：元素的宽度 = 你设置的宽度（包含 padding 和 border）*/
  box-sizing: border-box;
}
```

盒模型计算方式的对比：

```css
/* 默认 content-box */
.div1 {
  box-sizing: content-box;
  width: 100px;
  padding: 10px;
  border: 5px solid;
  /* 实际占用宽度：100 + 20 + 10 = 130px */
}

/* 使用 border-box */
.div2 {
  box-sizing: border-box;
  width: 100px;
  padding: 10px;
  border: 5px solid;
  /* 实际占用宽度：100px （内容区自动缩小为70px）*/
}
```

## 选择器优先级

### 单个选择器优先级比较

优先级规则：`**!important > id选择器 > class选择器 > 标签选择器 > 通配符选择器**`

在CSS中，通过对某一样式声明`!important` ，可以更改默认的CSS样式优先级规则，使该条样式属性声明具有最高优先级。

```css
.box {
  color:red !important;
}
```

### 复合选择器优先级比较

复合选择器优先级：由 **三个级别和各级别的出现次数 **决定的，三个级别对应的是：id选择器、class选择器、标签选择器。

- 先比较复合选择器中`id选择器`出现的次数，谁出现的次数多，则优先级更高，反之则优先级低；
- 如果复合选择器中的`id选择器`出现的次数相同，则比较`class选择器`出现的次数，谁出现的次数多，则优先级更高，反之则优先级低；
- 如果复合选择器中的`class选择器`出现的次数相同，则比较`标签选择器`出现的次数，谁出现的次数多，则优先级更高，反之则优先级低。

```html
<!DOCTYPE html>
<html>
<head>
<style>
  div.container { color: blue; }
  .container.box { color: green; }
  #main p.highlight { color: red; }
  .highlight { color: orange; }
  p { color: purple; }
</style>
</head>
<body>
  <div id="main" class="container box">
    <p class="text highlight">这段文字显示为红色</p>
  </div>
</body>
</html>
```

**记住口诀： ID > Class > 标签**，同级比较数量，就像打牌比大小！

### 优先级相同

优先级相同时，则采用就近原则，选择最后出现的样式。

```html
<!DOCTYPE html>
<html>
<head>
<style>
  /* 两个选择器优先级相同：(0,2,0) */
  .text.special {
    color: blue;
  }
  
  .special.text {
    color: red;  /* 这个生效，因为它在后面 */
  }
</style>
</head>
<body>
  <p class="text special">这段文字显示为红色</p>
</body>
</html>
```

# CSS常用属性

## 背景属性

CSS 允许应用纯色作为背景，也允许使用背景图像创建相当复杂的效果。

| **属性名** | **说明** |
| --- | --- |
| background-color | 设置元素的背景颜色 |
| background-image | 背景图片 |
| background-repeat | 背景重复 |

### background-color

使用 background-color 属性为元素设置背景色，其默认值是 transparent 也就是“透明”的意思，可使用`颜色名称、RGB、十六进制数`来指定颜色。

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .box {
        background-color: red;
    }
  </style>
</head>
<body>
  <div class="box">这个div有红色背景</div>
</body>
</html>
```

### background-image

使用 background-color 属性为元素设置背景图片，其默认值是 none，表示背景上没有放置任何图像。

如果需要设置一个背景图像，需要为这个属性设置URL或设置一个图片路径。

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .box {
        background-image: url("img/dogx.jpg");
        width: 600px;
        height: 600px;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
</html>
```

### background-repeat

使用 background-repeat 属性设置背景图片是否重复：

- repeat 重复（默认值）
- repeat-x 图片在横向上平铺
- repeat-y 图片在纵向上平铺
- no-repeat 不重复平铺

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .box {
        background-image: url("img/dogx.jpg");
        width: 600px;
        height: 600px;
        background-color: antiquewhite;
        background-repeat: no-repeat;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
</html>
```

### background-position

使用background-position 属性改变图像在背景中的位置

可以使用长度值，如 100px，也可以使用百分数值。

可以使用一些关键字：top、bottom、left、right 和 center，不能超过两个关键字，一个对应水平方向，另一个对应垂直方向。

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .box {
        background-image: url("img/dogx.jpg");
        width: 600px;
        height: 600px;
        background-color: antiquewhite;
        background-repeat: no-repeat;
        /* 左200px 上100px */
        background-position: 200px 100px;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
</html>
```

### background-attachment

设置背景图像是否跟随滚动条的滚动而滚动。

- scroll 滚动
- fixed 不滚动

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      height: 2000px;
      background-image: url("img/dogx.jpg");
      background-attachment: fixed;
    }
  </style>
</head>
<body>
</body>
</html>
```

## 文本属性

CSS 文本属性可定义文本的外观。通过文本属性，可以改变文本的颜色，字符间距，对齐文本，装饰文本，对文本进行缩进等等。

### color文本的颜色

可使用颜色名称、RGB、十六进制数来指定颜色。

### opacity

opacity 用来设置透明度，默认值为1，1为不透明，0为完全透明。

`p{ opacity: 0;}` 隐藏一个元素 ，完全不显示，但是会占空间，只是看不到。

可以设置字体的透明度，也可以设置div等元素的透明度。

### font字体设置

| **属性名** | **作用** | **参数说明** |
| --- | --- | --- |
| font-family | 字体名称 | 例如：Arial，"微软雅黑"，"宋体" |
| font-size | 字体大小 | 例如：18px，2em |
| font-style | 字体风格 | normal(缺省)，italic, oblique |
| font-weight | 字体粗细 | normal(缺省)，bold或数值 |

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .title {
        /* 设置字体名字 */
        font-family: "宋体", "微软雅黑", Arial;
        /* 设置字体大小 */
        font-size: 2em;
        /* 设置字体粗细 */
        font-weight: 900;
        /* 设置字体风格 */
        font-style: italic;
    }
  </style>
</head>
<body>
  <div class="title">这是一个带有样式的标题</div>
</body>
</html>
```

### text-align

文本对齐属性 text-align 规定元素中的文本的水平对齐方式，只能设置块级元素内文本的水平对齐方式。

| **属性值** | **描述说明** |
| --- | --- |
| left | 把文本排列到左边。默认值：由浏览器决定。 |
| right | 把文本排列到右边。 |
| center | 把文本排列到中间。 |
| justify | 两端对齐 |

```css
<!DOCTYPE html>
<html>
<head>
  <style>
    p {
      width: 300px;
      border: 1px solid #000;
      margin: 10px;
      padding: 10px;
    }
    .left { text-align: left; }
    .center { text-align: center; }
    .right { text-align: right; }
  </style>
</head>
<body>
  <p class="left">这段文本左对齐</p>
  <p class="center">这段文本居中对齐</p>
  <p class="right">这段文本右对齐</p>
</body>
</html>
```

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .title {
      background-color: antiquewhite;
      text-align: justify;
      width: 500px;
      padding: 10px;
    }
  </style>
</head>
<body>
  <div class="title">这是一段较长的文本内容，需要足够多的文字才能看到两端对齐的效果。当文本超过一行时，justify属性会让每行的左右两边都对齐到容器边缘。</div>
</body>
</html>
```

### text-decoration字体装饰

| **属性值** | **描述说明** |
| --- | --- |
| none | 默认，定义标准的文本。 |
| underline | 定义文本下的一条线。 |

| line-through | 定义穿过文本下的一条线。 |

# 元素的分类

元素主要分为：块级元素、内联元素和内联块级元素。

## 块级元素

常见的块级元素有：body，div，p，h1~h6，ul，ol，li，pre等。

块级元素具有以下特点：

1. 总是在新行上开始，占据一整行；
2. 高度属性（height）和宽度属性（width）可以设置，并且可设置四个方向的`padding`和`margin`值；
  1. padding（内边距）：设置元素内容与边框之间的空间（向内扩展）。
  2. margin（外边距）：设置元素与其他元素之间的空白距离（向外扩展）。
3. 宽始终是与父元素宽度一样，与内容无关；
4. 它可以容纳**内联元素**和**其它块级元素**。

通过`display:block`可以将元素显示设置为块级元素。如下的代码就是将`内联元素a`转成`块级元素`，从而使a元素具有块元素的特点：

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    a { 
      display: block; /* 把一个内联元素变成块级元素 */
      margin: 5px;
      padding: 10px;
      background: lightblue;
      text-decoration: none;
      border: 1px solid #333;
    }
  </style>
</head>
<body>
  <a href="#">链接1 - 现在是块级元素</a>
  <a href="#">链接2 - 独占一行</a>
  <a href="#">链接3 - 可以设置宽高边距</a>
</body>
</html>
```

## 内联元素

常见的行内元素有：**a，span** 等。

内联元素的特点：

1. 可以和别的内联元素和内联块级元素共享一行；
2. 不能设置高度属性（height）和宽度属性（width），另外只能设置左右方向的padding和margin值；
3. 内联元素的宽度只与内容有关；
4. 内联元素只能容纳文本或者其他内联元素。

通过`display:inline`可以将元素显示设置为内联元素，如下的代码就是将块级元素div转成内联元素，从而使div元素具有内联元素的特点：

```html

      background: lightblue;
      margin: 5px;
      padding: 10px;
    }
  </style>
</head>

  <div>div2 - 不换行显示</div>

  普通文本
</body>
</html>
```

# CSS布局

## 文档流

文档流（Normal Flow）是浏览器默认的页面元素排列方式：

- 块级元素从上到下垂直排列
- 内联元素从左到右水平排列
- 每个元素按照在HTML中的出现顺序依次排列

## 脱离文档流

什么叫做脱离文档流？就是它没有按照正常排队，没有在应该在的位置，就是脱离文档流。

第一种情况： float（浮动）

- 元素脱离文档流，向左或向右浮动（相对于父容器来说的，**浮动到当前位置的上方**。）
- **其他块级元素会忽略它的存在**，但文本不会（文本内容会环绕在浮动元素周围）

第二种情况： position: absolute / fixed（绝对/固定定位）

- 完全脱离文档流
- 不占据原来的空间位置
- 其他元素会完全填充它原来的位置

第三种情况： position: relative（相对定位）的特殊性

- **不会脱离文档流**
- 元素仍然占据原来的空间位置
- 只是视觉上发生偏移

`**<font style="color:rgb(15, 17, 21);">display: none</font>**`** 不会"脱离文档流"，而是直接从渲染树中移除。脱离文档流：元素还在页面上，只是不占原来的位置。**

### float 布局的高度塌陷问题

什么是高度塌陷？

高度塌陷是指：当父元素包含浮动子元素时，父元素的高度会变成0，就像"塌陷"了一样。

【示例】

```html
<!DOCTYPE html>
<html>
<head>
<style>
  .parent {
    border: 3px solid red;
    padding: 10px;
  }
  .child {
    float: left;
    width: 100px;
    height: 100px;
    background: lightblue;
  }
</style>
</head>
<body>
  <div class="parent">
    <div class="child">浮动子元素</div>
  </div>
</body>
</html>
```

编写两个例子大家对比一下就知道了，通常可以通过在父元素上添加 `overflow:hidden`样式来解决高度塌陷的问题。我们称这个样式叫做清除浮动。

下面我们来看两个例子，一个是存在高度塌陷的，一个是解决高度塌陷问题的。

存在高度塌陷问题：

## 脱离文档流之 position 布局

### position 属性值

position 属性有五个主要值：

#### static（默认值）

- 元素按照正常的文档流排列
- top, right, bottom, left 和 z-index 属性无效
- 这是所有元素的默认定位方式

```css
.box {
  position: static;
}
```

#### relative（相对定位）

- 元素先放置在未添加定位时的位置
- 然后可以通过 top, right, bottom, left 调整位置
- 不影响其他元素的位置（其他元素仍认为该元素在原来的位置）

```css
.box {
  position: relative;
  top: 20px;
  left: 30px;
}
```

#### absolute（绝对定位）

- 元素脱离正常文档流
- 相对于最近的已定位祖先元素（position 不是 static）定位
- 如果没有已定位的祖先元素，则相对于视口。***什么是视口：浏览器窗口中实际显示网页内容的区域（不包括地址栏、书签栏等浏览器自身界面），视口会随着窗口大小的变化而变化。***
- 会创建新的层叠上下文

```css
.container {
  /* 一般使用relative来设置参照物，把这个元素当做一个祖先元素。让 position: absolute的元素有一个参照物。 */
  position: relative;
}

.box {
  position: absolute;
  top: 0;
  right: 0;
}
```

#### fixed（固定定位）

- 元素脱离正常文档流
- 相对于视口定位
- 不随页面滚动而移动
- 会创建新的层叠上下文

```css
.header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}
```

### 定位属性的使用技巧

- 相对定位常用于微调元素位置或作为绝对定位元素的容器
- 绝对定位常用于创建弹出层、工具提示等
- 固定定位适合导航栏、侧边栏等需要常驻的元素

## z-index 层叠顺序

### 基本概念

z-index 属性控制定位元素在垂直于屏幕方向（z轴）上的堆叠顺序：

- 值越大，元素越靠近用户
- 只对定位元素（position 不是 static）有效
- 默认 auto（相当于 0）

```css
.box1 {
  position: absolute;
  z-index: 1;
}

.box2 {
  position: absolute;
  z-index: 2; /* 这个元素会显示在 box1 上方 */
}
```

```html
    height: 100px;

  }
  
  .box2 {
    background: blue;

    top: 50px;
    left: 50px;
```

## Flex 布局

flex 布局是用来代替 float 布局的。Flex布局更直观、更易控制，不需要处理浮动带来的布局塌陷和清除浮动问题。

```html
<!DOCTYPE html>
<html>
<head>
<style>
  .container {
    /* 要使用flex布局，必须在父容器上设置display样式为flex */
    display: flex;
  }
  .item {
    flex: 1; /* 每个item平均分配剩余空间 */
    background: lightblue;
    margin: 5px;
    padding: 20px;
  }
</style>
</head>
<body>
  <div class="container">
    <div class="item">项目1</div>
    <div class="item">项目2</div>
    <div class="item">项目3</div>
  </div>
</body>
</html>
```
