## 二、后端任务（SpringBoot + MyBatis）

### 2.1 核心需求

实现一个分页查询接口，支持按姓名和专业进行模糊查询。

### 2.2 需要实现的接口

#### 接口：分页查询学生列表

- **请求方法**: GET
- **请求路径**: `/api/students/page`
- **请求参数**:

```json
{
  "pageNum": 1,      // 当前页码，默认1
  "pageSize": 10,    // 每页大小，默认10
  "name": "",        // 学生姓名（模糊查询，可选）
  "major": ""        // 专业（模糊查询，可选）
}
```

- **响应格式**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 30,
    "pages": 3,
    "list": [
      {
        "id": 1,
        "studentNo": "S20240001",
        "name": "张三",
        "gender": "男",
        "age": 20,
        "major": "计算机科学与技术",
        "className": "计科1班",
        "createTime": "2024-01-01 10:00:00"
      }
    ]
  }
}
```

### 2.3 技术要点

1. 使用MyBatis实现数据访问
2. 使用PageHelper实现分页
3. 支持动态条件查询（姓名、专业）
4. 添加跨域配置支持

## 三、前端任务（Vue3 + ElementPlus）

### 3.1 页面要求

创建一个学生列表页面，包含：

1. 搜索区域：可按姓名和专业搜索
2. 表格区域：显示学生信息
3. 分页区域：显示分页控件

### 3.2 页面布局参考

```plaintext
<template>
  <div class="container">
    <!-- 搜索框 -->
    <div class="search-box">
      <el-input v-model="queryParams.name" placeholder="请输入姓名" />
      <el-input v-model="queryParams.major" placeholder="请输入专业" />
      <el-button type="primary" @click="handleSearch">搜索</el-button>
    </div>
    
    <!-- 学生表格 -->
    <el-table :data="studentList" border style="width: 100%">
      <el-table-column prop="studentNo" label="学号" width="120" />
      <el-table-column prop="name" label="姓名" width="100" />
      <el-table-column prop="gender" label="性别" width="80" />
      <el-table-column prop="age" label="年龄" width="80" />
      <el-table-column prop="major" label="专业" />
      <el-table-column prop="className" label="班级" />
      <el-table-column prop="createTime" label="创建时间" width="180" />
    </el-table>
    
    <!-- 分页 -->
    <el-pagination
      v-model:current-page="queryParams.pageNum"
      v-model:page-size="queryParams.pageSize"
      :total="total"
      @current-change="handlePageChange"
      @size-change="handleSizeChange"
      layout="total, sizes, prev, pager, next, jumper"
    />
  </div>
</template>
```

### 3.3 功能要求

1. 页面加载时自动加载第一页数据
2. 支持按姓名和专业进行模糊搜索
3. 点击搜索按钮时，重置到第一页
4. 分页切换时，重新加载对应页面的数据
5. 表格数据为空时显示友好提示
