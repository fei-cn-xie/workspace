# 司机注册

司机使用的是微信小程序，因此司机注册的时候应该**使用微信号进行注册**。

## 功能时序图

![7b6fd8e6-b4e5-4448-a8cb-595193f723ff.png](images/RAf3beM9NoEY7RxvycUch28Un9V.png)

1. `**<font style="color:#000000;">bff-driver</font>**`**（司机 bff）子系统远程调用 **`**<font style="color:#000000;">zxds-dr</font>**`**（司机）子系统。核心业务在 **`**<font style="color:#000000;">zxds-dr</font>**`**（司机）子系统中进行。**
2. **openId 是什么？**
  1. 当用户首次使用小程序时，微信平台根据用户的微信号和小程序的AppID通过加密算法生成一个唯一的、永久不变的OpenID，作为该用户在这个小程序中的专属身份标识。（openId 是这个用户在当前小程序中的身份证号，由微信平台生成，永不变。）
3. **在后端 Java 程序中怎么获取 openId？**
  1. 通过 Java 程序调用微信平台提供的接口来获取。调用微信平台接口时，需要给接口传一个 code 参数。
4. **code 参数是什么？**
  1. code 是微信小程序用户的临时登录凭证，是微信服务器分配的。
  2. 用户打开微信，然后登录微信，用户搜索小程序，找到小程序并点击小程序，在小程序中我们会调用这个 API：`<font style="color:#000000;">uni.login()</font>`，向微信服务器发送请求，微信服务器判断该用户是否已经登录微信，如果该用户已登录微信，则微信服务器会向微信小程序响应一个 5 分钟之内有效的临时登录凭证。这个临时登录凭证就是 code。
5. **核心业务流程梳理：**
  1. 根据 code 获取 openId
  2. 根据 openId 看看后端数据库里有没有这个司机。
  3. 如果没有这个司机（表示该司机未注册），则保存司机信息。司机信息的主键值采用雪花算法生成。
  4. 保存司机的**设置信息**，设置信息以**默认设置**保存。
  5. 保存司机的钱包信息，钱包余额为 0
  6. 最后将 driverId 返回，bff 层接收到 driverId 后，通过 driverId 生成 Token

### 保存司机的默认设置

`<font style="color:#000000;">tb_driver_settings</font>` 表保存的司机在小程序上的设置，比如：是否自动抢单；附近多少公里以内的订单，自己才会接单。

| **字段** | **类型** | **禁止空值** | **备注信息** |
| --- | --- | --- | --- |
| id | bigint | True | 主键 |
| driver_id | bigint | True | 司机ID |
| settings | json | True | 司机个人设置 |

settings字段里面的内容是JSON格式的，具体例子如下：

```json
{
  "autoAccept": 0, // 1自动抢单，0不自动抢单
  "orientation": "", //定向接单（这里存储的是一个GPS定位坐标值）
  "listenService": true,  //语音播报订单，false表示不进行语音播报
  "orderDistance": 0, //代驾订单预估里程不限，司机不挑订单
  "rangeDistance": 5  //接收距离司机5公里以内的代驾单
}
```

**详细解释：**

1. `orientation`：定向接单这里是一个坐标值，规则是：主要看**乘客订单的终点坐标值**与**司机设置的定向接单的坐标值**之间的距离是否**在 3000 米以内（3 公里）**，在 3 公里以内，则这个订单符合司机的接单要求。比如说司机想回家了，那就可以设置定向接单的方向是家的方向。这样等于回家的时候顺带着接个单。
2. `orderDistance`：对订单的起点到终点的距离进行限制，0 表示不限制。在我们代驾系统中的业务是这样要求的，如果
  1. `orderDistance=5`表示订单的起点到终点的距离是 `>0 and <=5`
  2. `orderDistance=10`表示订单的起点到终点的距离是 `>5 and <=10`
  3. `orderDistance=15`表示订单的起点到终点的距离是 `>10 and <=15`
  4. `orderDistance=30`表示订单的起点到终点的距离是 `>15 and <=30`
3. `rangeDistance`：设置司机只接距离自己几公里以内的单子。

**找到 **`**<font style="color:#000000;">DriverSettingsDao.xml</font>**`**文件，编写以下 SQL：**

```xml
<insert id="insertDriverSettings" parameterType="com.example.zxds.dr.db.pojo.DriverSettingsEntity">

    SET id = #{id},
        driver_id = #{driverId},
        settings = #{settings}
</insert>
```

## 编写业务层

在 `<font style="color:#000000;">com.example.zxds.dr.service</font>` 包中创建 `<font style="color:#000000;">DriverService</font>` 接口，声明抽象业务方法：

在 `<font style="color:#000000;">com.example.zxds.dr.service.impl</font>` 包中创建 `<font style="color:#000000;">DriverServiceImpl</font>` 类，实现业务方法，添加本地事务。

```java
package com.example.zxds.dr.service.impl;

import cn.hutool.core.map.MapUtil;
import cn.hutool.core.util.IdUtil;
import cn.hutool.json.JSONObject;
import com.example.zxds.common.exception.ZxdsException;
import com.example.zxds.common.util.MicroAppUtil;
import com.example.zxds.dr.db.dao.DriverDao;
import com.example.zxds.dr.db.dao.DriverSettingsDao;
import com.example.zxds.dr.db.dao.WalletDao;
import com.example.zxds.dr.db.pojo.DriverSettingsEntity;
import com.example.zxds.dr.db.pojo.WalletEntity;
import com.example.zxds.dr.service.DriverService;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import javax.annotation.Resource;
import java.math.BigDecimal;
import java.util.HashMap;
import java.util.Map;

@Service
@Slf4j
public class DriverServiceImpl implements DriverService {
    @Resource
    private MicroAppUtil microAppUtil;

    @Resource
    private DriverDao driverDao;

    @Resource
    private DriverSettingsDao settingsDao;

    @Resource
    private WalletDao walletDao;

    @Override
    @Transactional
    public String registerNewDriver(Map<String, Object> param) {
        // 获取code，通过code获取openId
        String code = MapUtil.getStr(param, "code");
        String openId = microAppUtil.getOpenId(code);

        // 看看该司机有没有注册过。
        Map<String, Object> tempParam = new HashMap<>();
        tempParam.put("openId", openId);
        if (driverDao.hasDriver(tempParam) != 0) {
            throw new ZxdsException("该微信无法注册");
        }

        // 保存司机数据
        // 通过雪花算法生成主键值：第一个参数workerId，第二个参数datacenterId
        // workerId表示终端id（一张表一个）
        // datacenterId表示数据中心id（同一个模块中这个值不变）
        long driverId = IdUtil.getSnowflake(1, 1).nextId(); // 建议这里封装一个工具类。
        param.put("driverId", driverId);
        param.put("openId", openId);
        String nickname = MapUtil.getStr(params, "nickname");
        String photo = MapUtil.getStr(params, "photo");
        param.put("nickname", nickname);
        param.put("photo", photo);
        driverDao.registerNewDriver(param); //插入司机记录

        //添加司机默认设置
        DriverSettingsEntity settingsEntity = new DriverSettingsEntity();
        settingsEntity.setId(IdUtil.getSnowflake(2, 1).nextId());
        settingsEntity.setDriverId(driverId);
        JSONObject json = new JSONObject();
        json.set("orientation", "");
        json.set("listenService", true);
        json.set("orderDistance", 0);
        json.set("rangeDistance", 5);
        json.set("autoAccept", false);
        settingsEntity.setSettings(json.toString());
        settingsDao.insertDriverSettings(settingsEntity);

        //添加司机钱包记录
        WalletEntity walletEntity = new WalletEntity();
        walletEntity.setId(IdUtil.getSnowflake(3, 1).nextId());
        walletEntity.setDriverId(driverId);
        walletEntity.setBalance(new BigDecimal("0"));
        walletEntity.setPassword(null); //支付密码为空，用户支付的时候，系统会自动提示用户设置支付密码
        walletDao.insert(walletEntity);

        // 为什么要返回一个字符串？因为雪花算法生成了一个long类型的数字，前端和移动端不支持。
        return String.valueOf(driverId);
    }
}
```

```java
package com.example.zxds.bff.driver.service.impl;

import cn.hutool.core.convert.Convert;
import com.example.zxds.bff.driver.controller.form.RegisterNewDriverForm;
import com.example.zxds.bff.driver.feign.DrServiceApi;
import com.example.zxds.bff.driver.service.DriverService;

import org.springframework.stereotype.Service;

import javax.annotation.Resource;

@Service
public class DriverServiceImpl implements DriverService {

    @Resource
    private DrServiceApi drServiceApi;

    @Override
    @GlobalTransactional // 分布式事务

        long userId = Convert.toLong(r.get("userId"));
        return userId;
```

```java
import cn.dev33.satoken.stp.StpUtil;

@RequestMapping("/driver")
@Tag(name = "DriverController", description = "司机模块Web接口")
```

### 发送 ajax 请求注册

在注册页面找到**立即注册**按钮：`<font style="color:#000000;">pages/register/register.vue</font>`

编写 `<font style="color:#000000;">register()</font>`函数：**在 HBuilderX 中唤醒提示的默认快捷键是 **`**<font style="color:#000000;">alt + /</font>**`**，搜索文件的快捷键是 **`**<font style="color:#000000;">ctrl + p</font>**`

```javascript
register: function() {
    // 把this临时保存到一个普通变量中
    // 因为在下面的回调函数中如果都是直接使用this，那么this的指向改变了。
    // 这里的this是vue组件实例。
    let that = this;
  
    // uni-app的内置API，通过这个方法：向微信官方申请一个临时凭证
    uni.login({
        provider: 'weixin', // uni-app 支持多平台登录，所以需要指定，也可以是qq
        success: function(resp) {
            let code = resp.code;
            that.code = code;
        }
    });
    // uni-app 封装的微信小程序API，用于获取用户真实的昵称和头像等信息，调用时会弹出授权窗口要求用户明确同意，符合微信平台的隐私保护政策
    uni.getUserProfile({
        desc: '获取用户信息', // 必须的描述信息，显示在授权弹窗
        success: function(resp) {
            // 获取信息
            let nickname = resp.userInfo.nickName;
            let avatarUrl = resp.userInfo.avatarUrl;
            // 封装数据
            let data = {
                code: that.code,
                nickname: nickname,
                photo: avatarUrl
            };
            // 注意：uni-app不支持axios。这里采用原生ajax请求，这个ajax函数是封装的工具。
            that.ajax(that.url.registerNewDriver, 'POST', data, function(resp) {
              
                let token = resp.data.token;
                // 存储到小程序的本地存储中，微信小程序的本地缓存（不是手机本地文件）
                uni.setStorageSync('token', token);
                uni.setStorageSync('realAuth', 1);
              
                // uView UI 是 uni-app 生态的跨平台 UI 组件库，类似 Element UI
                // 调用 uView UI 的 Toast 组件显示成功提示，2秒后自动跳转到信息填写页面
                // 代码对应的是页面中的：<u-toast ref="uToast" />
                // 如果代码是这样的：<u-toast ref="abc" />
                // 那么下面代码就可以这样写：that.$refs.abc.show()
                that.$refs.uToast.show({
                    title: '注册成功',
                    type: 'success',
                    callback: function() {
                        uni.redirectTo({
                            url: '../../identity/filling/filling?mode=create'
                        });
                    }
                });
            });
        }
    });
}
```

## 封装云存储操作

我在 `<font style="color:#000000;">common</font>` 子系统的 `<font style="color:#000000;">com.example.zxds.common.util</font>` 包中，封装了 `<font style="color:#000000;">CosUtil</font>`工具类，封装了对存储桶文件的基本操作。例如**上传文件、图片审核、获取隐私文件的临时外网URL地址、删除文件**等操作。

```java
package com.example.zxds.common.util;

import cn.hutool.core.date.DateUtil;
import cn.hutool.core.util.IdUtil;
import com.example.zxds.common.exception.ZxdsException;
import com.qcloud.cos.COSClient;
import com.qcloud.cos.ClientConfig;
import com.qcloud.cos.auth.BasicCOSCredentials;
import com.qcloud.cos.auth.COSCredentials;
import com.qcloud.cos.http.HttpMethodName;
import com.qcloud.cos.http.HttpProtocol;
import com.qcloud.cos.model.*;
import com.qcloud.cos.model.ciModel.auditing.ImageAuditingRequest;
import com.qcloud.cos.model.ciModel.auditing.ImageAuditingResponse;
import com.qcloud.cos.region.Region;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.net.URL;
import java.util.Date;
import java.util.HashMap;
import java.util.List;

@Component
public class CosUtil {
    @Value("${tencent.cloud.appId}")
    private String appId;

    @Value("${tencent.cloud.secretId}")
    private String secretId;

    @Value("${tencent.cloud.secretKey}")
    private String secretKey;

    @Value("${tencent.cloud.region-public}")
    private String regionPublic;

    @Value("${tencent.cloud.bucket-public}")
    private String bucketPublic;

    @Value("${tencent.cloud.region-private}")
    private String regionPrivate;

    @Value("${tencent.cloud.bucket-private}")
    private String bucketPrivate;

    //获取访问公有存储桶的连接
    private COSClient getCosPublicClient() {
        COSCredentials cred = new BasicCOSCredentials(secretId, secretKey);
        ClientConfig clientConfig = new ClientConfig(new Region(regionPublic));
        clientConfig.setHttpProtocol(HttpProtocol.https);
        COSClient cosClient = new COSClient(cred, clientConfig);
        return cosClient;
    }

    //获得访问私有存储桶的连接
    private COSClient getCosPrivateClient() {
        COSCredentials cred = new BasicCOSCredentials(secretId, secretKey);
        ClientConfig clientConfig = new ClientConfig(new Region(regionPrivate));
        clientConfig.setHttpProtocol(HttpProtocol.https);
        COSClient cosClient = new COSClient(cred, clientConfig);
        return cosClient;
    }

    /**
     * 向公有存储桶上传文件
     */
    public HashMap uploadPublicFile(MultipartFile file, String path) throws IOException {
        String fileName = file.getOriginalFilename(); //上传文件的名字
        String fileType = fileName.substring(fileName.lastIndexOf(".")); //文件后缀名
        path += IdUtil.simpleUUID() + fileType; //避免重名图片在云端覆盖，所以用UUID作为文件名

        //元数据信息
        ObjectMetadata meta = new ObjectMetadata();
        meta.setContentLength(file.getSize());
        meta.setContentEncoding("UTF-8");
        meta.setContentType(file.getContentType());

        //向存储桶中保存文件
        PutObjectRequest putObjectRequest = new PutObjectRequest(bucketPublic, path, file.getInputStream(), meta);
        putObjectRequest.setStorageClass(StorageClass.Standard); //标准存储
        COSClient client = getCosPublicClient();
        PutObjectResult putObjectResult = client.putObject(putObjectRequest);


        //合成外网访问地址（外网地址格式参考这个文档：https://cloud.tencent.com/document/product/436/6224）
        HashMap map = new HashMap();
        map.put("url", "https://" + bucketPublic + ".cos." + regionPublic + ".myqcloud.com" + path);
        map.put("path", path);

        //如果保存的是图片，用数据万象服务对图片内容审核
        if (List.of(".jpg", ".jpeg", ".png", ".gif", ".bmp").contains(fileType)) {
            //审核图片内容
            ImageAuditingRequest request = new ImageAuditingRequest();
            request.setBucketName(bucketPublic);
            request.setDetectType("porn,terrorist,politics,ads"); //辨别黄色、暴利、政治和广告内容
            request.setObjectKey(path);
            ImageAuditingResponse response = client.imageAuditing(request); //执行审查

            if (!response.getPornInfo().getHitFlag().equals("0") || !response.getTerroristInfo().getHitFlag().equals("0") || !response.getPoliticsInfo().getHitFlag().equals("0") || !response.getAdsInfo().getHitFlag().equals("0")) {
                //删除违规图片
                client.deleteObject(bucketPublic, path);
                throw new ZxdsException("图片内容不合规");
            }
        }
        client.shutdown();
        return map;
    }

    /**
     * 向私有存储桶上传文件
     */
    public HashMap uploadPrivateFile(MultipartFile file, String path) throws IOException {
        String fileName = file.getOriginalFilename(); //上传文件的名字
        String fileType = fileName.substring(fileName.lastIndexOf(".")); //文件后缀名
        path += IdUtil.simpleUUID() + fileType; //避免重名图片在云端覆盖，所以用UUID作为文件名

        //元数据信息
        ObjectMetadata meta = new ObjectMetadata();
        meta.setContentLength(file.getSize());
        meta.setContentEncoding("UTF-8");
        meta.setContentType(file.getContentType());

        //向存储桶中保存文件
        PutObjectRequest putObjectRequest = new PutObjectRequest(bucketPrivate, path, file.getInputStream(), meta);
        putObjectRequest.setStorageClass(StorageClass.Standard);
        COSClient client = getCosPrivateClient();
        PutObjectResult putObjectResult = client.putObject(putObjectRequest); //上传文件

        HashMap map = new HashMap();
        map.put("path", path);

        //如果保存的是图片，用数据万象服务对图片内容审核
        if (List.of(".jpg", ".jpeg", ".png", ".gif", ".bmp").contains(fileType)) {
            //审核图片内容
            ImageAuditingRequest request = new ImageAuditingRequest();
            request.setBucketName(bucketPrivate);
            request.setDetectType("porn,terrorist,politics,ads"); //辨别黄色、暴利、政治和广告内容
            request.setObjectKey(path);
            ImageAuditingResponse response = client.imageAuditing(request); //执行审查

            if (!response.getPornInfo().getHitFlag().equals("0") || !response.getTerroristInfo().getHitFlag().equals("0") || !response.getPoliticsInfo().getHitFlag().equals("0") || !response.getAdsInfo().getHitFlag().equals("0")) {
                //删除违规图片
                client.deleteObject(bucketPrivate, path);
                throw new ZxdsException("图片内容不合规");
            }
        }
        client.shutdown();
        return map;

    }

    /**
     * 获取私有文件的临时URL外网访问地址
     */
    public String getPrivateFileUrl(String path) {
        COSClient client = getCosPrivateClient();
        GeneratePresignedUrlRequest request = new GeneratePresignedUrlRequest(bucketPrivate, path, HttpMethodName.GET);
        Date expiration = DateUtil.offsetMinute(new Date(), 5);  //设置临时URL有效期为5分钟
        request.setExpiration(expiration);
        URL url = client.generatePresignedUrl(request);
        client.shutdown();
        return url.toString();
    }

    /**
     * 刪除公有存储桶的文件
     */
    public void deletePublicFile(String[] pathes) {
        COSClient client = getCosPublicClient();
        for (String path : pathes) {
            client.deleteObject(bucketPublic, path);
        }
        client.shutdown();
    }

    /**
     * 刪除私有存储桶的文件
     */
    public void deletePrivateFile(String[] pathes) {
        COSClient client = getCosPrivateClient();
        for (String path : pathes) {
            client.deleteObject(bucketPrivate, path);
        }
        client.shutdown();
    }

}
```

在 `<font style="color:#000000;">common</font>`项目中封装 `<font style="color:#000000;">OcrUtil</font>`，封装身份证识别和驾驶证识别，代码如下：

```java
package com.example.zxds.common.util;

import com.baidu.aip.ocr.AipOcr;
import com.example.zxds.common.exception.ZxdsException;
import org.json.JSONObject;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Component
public class OcrUtil {
    @Value("${baidu.cloud.appId}")
    public String appId;
    @Value("${baidu.cloud.appKey}")
    public String apiKey;
    @Value("${baidu.cloud.secretKey}")
    public String secretKey;

    // 初始化客户端对象
    private AipOcr client;

    /**
     * 初始化OCR客户端（懒加载）
     */
    private AipOcr getClient() {
        if (client == null) {
            client = new AipOcr(appId, apiKey, secretKey);
            // 可选：设置网络连接参数
            client.setConnectionTimeoutInMillis(2000);
            client.setSocketTimeoutInMillis(60000);
        }
        return client;
    }

    /**
     * 识别身份证正面（含照片面）
     *
     * @param file 身份证正面图片文件
     * @return JSON格式的识别结果
     */
    public JSONObject recognizeIdCardFront(MultipartFile file) {
        return recognizeIdCard(file, "front");
    }

    /**
     * 识别身份证背面（国徽面）
     *
     * @param file 身份证背面图片文件
     * @return JSON格式的识别结果
     */
    public JSONObject recognizeIdCardBack(MultipartFile file) {
        return recognizeIdCard(file, "back");
    }

    /**
     * 识别身份证（通用方法）
     *
     * @param file 图片文件
     * @param side 正反面："front"或"back"
     * @return JSON格式的识别结果
     */
    public JSONObject recognizeIdCard(MultipartFile file, String side) {
        if (file.isEmpty()) {
            throw new ZxdsException("上传文件不能为空");
        }

        try {
            // 将MultipartFile转换为字节数组
            byte[] imageBytes = file.getBytes();

            // 设置可选参数
            HashMap<String, String> options = new HashMap<>();
            options.put("detect_direction", "true");  // 检测图片方向
            options.put("detect_risk", "false");      // 不开启风险类型检测

            // 调用身份证识别接口
            return getClient().idcard(imageBytes, side, options);

        } catch (IOException e) {
            throw new ZxdsException("读取文件失败: " + e.getMessage());
        } catch (Exception e) {
            throw new ZxdsException("识别失败: " + e.getMessage());
        }
    }

    /**
     * 从识别结果中提取关键字段（正面示例）
     *
     * @param result 识别结果
     * @return 简化的关键信息Map
     */
    public Map<String, String> extractFrontInfo(JSONObject result) {
        Map<String, String> info = new HashMap<>();

        if (result != null && result.getString("image_status").equals("normal")) {
            JSONObject wordsResult = result.getJSONObject("words_result");

            // 提取正面字段
            if (wordsResult.has("姓名")) {
                info.put("name", wordsResult.getJSONObject("姓名").getString("words"));
            }
            if (wordsResult.has("公民身份号码")) {
                info.put("idNumber", wordsResult.getJSONObject("公民身份号码").getString("words"));
            }
            if (wordsResult.has("性别")) {
                info.put("gender", wordsResult.getJSONObject("性别").getString("words"));
            }
            if (wordsResult.has("出生")) {
                info.put("birth", wordsResult.getJSONObject("出生").getString("words"));
            }
            if (wordsResult.has("住址")) {
                info.put("address", wordsResult.getJSONObject("住址").getString("words"));
            }
            if (wordsResult.has("民族")) {
                info.put("nation", wordsResult.getJSONObject("民族").getString("words"));
            }
        } else {
            throw new ZxdsException("识别失败: " + (result != null ? result.toString() : "结果为空"));
        }

        return info;
    }

    /**
     * 从识别结果中提取关键字段（背面示例）
     *
     * @param result 识别结果
     * @return 简化的关键信息Map
     */
    public Map<String, String> extractBackInfo(JSONObject result) {
        Map<String, String> info = new HashMap<>();

        if (result != null && result.getString("image_status").equals("normal")) {
            JSONObject wordsResult = result.getJSONObject("words_result");

            // 提取背面字段
            if (wordsResult.has("签发机关")) {
                info.put("issuingAuthority", wordsResult.getJSONObject("签发机关").getString("words"));
            }
            if (wordsResult.has("失效日期")) {
                info.put("validPeriod", wordsResult.getJSONObject("失效日期").getString("words"));
            }
        } else {
            throw new ZxdsException("识别失败: " + (result != null ? result.toString() : "结果为空"));
        }

        return info;
    }


    /**
     * 识别驾驶证主页（正本）
     *
     * @param file 驾驶证主页图片文件
     * @return JSON格式的识别结果
     */
    public JSONObject recognizeDriverLicenseMainPage(MultipartFile file) {
        if (file.isEmpty()) {
            throw new ZxdsException("上传文件不能为空");
        }

        try {
            byte[] imageBytes = file.getBytes();

            HashMap<String, String> options = new HashMap<>();
            options.put("detect_direction", "true");
            options.put("unified_valid_period", "true");

            return getClient().drivingLicense(imageBytes, options);

        } catch (IOException e) {
            throw new ZxdsException("读取文件失败: " + e.getMessage());
        } catch (Exception e) {
            throw new ZxdsException("识别失败: " + e.getMessage());
        }
    }

    /**
     * 解析驾驶证主页（正本）信息
     * @param result 百度云OCR识别结果
     * @return 包含驾驶证主页信息的Map
     */
    public Map<String, String> parseDriverLicenseMainPageInfo(JSONObject result) {
        Map<String, String> info = new HashMap<>();

        if (result == null) {
            throw new ZxdsException("识别结果为空");
        }

        try {
            JSONObject wordsResult = result.getJSONObject("words_result");

            // 解析出初次领证日期（对应前端 issueDate）
            if (wordsResult.has("初次领证日期")) {
                String issueDateStr = wordsResult.getJSONObject("初次领证日期")
                        .getString("words");
                // 格式化为标准日期格式，如：2023-05-15
                String formattedDate = formatChineseDate(issueDateStr);
                info.put("issueDate", formattedDate);
            }

            // 解析出准驾车型（对应前端 carClass）
            if (wordsResult.has("准驾车型")) {
                String carClass = wordsResult.getJSONObject("准驾车型")
                        .getString("words");
                info.put("carClass", carClass);
            }

            // 解析出有效期（对应前端 validFrom 和 validTo）
            if (wordsResult.has("有效起始日期")) {
                String validFrom = wordsResult.getJSONObject("有效起始日期")
                        .getString("words");
                info.put("validFrom", validFrom);
            }
            if (wordsResult.has("失效日期")) {
                String validTo = wordsResult.getJSONObject("失效日期")
                        .getString("words");
                info.put("validTo", validTo);
            }

            // 也可以提取其他常用字段
            if (wordsResult.has("姓名")) {
                info.put("driverName", wordsResult.getJSONObject("姓名").getString("words"));
            }
            if (wordsResult.has("证号")) {
                info.put("licenseNumber", wordsResult.getJSONObject("证号").getString("words"));
            }

            return info;

        } catch (Exception e) {
            throw new ZxdsException("解析驾驶证信息失败: " + e.getMessage());
        }
    }

    /**
     * 格式化中文日期为标准格式
     * @param chineseDate 如："2023年05月15日"
     * @return 如："2023-05-15"
     */
    private String formatChineseDate(String chineseDate) {
        try {
            if (chineseDate.contains("年") && chineseDate.contains("月") && chineseDate.contains("日")) {
                // 去除中文年月日
                String dateStr = chineseDate.replace("年", "-")
                        .replace("月", "-")
                        .replace("日", "");
                // 确保格式正确
                SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
                Date date = sdf.parse(dateStr);
                return sdf.format(date);
            }
            return chineseDate; // 如果已经是标准格式，直接返回
        } catch (Exception e) {
            return chineseDate; // 解析失败，返回原字符串
        }
    }

    /**
     * 解析有效期字符串
     * @param validPeriod 如："20190515-20250515" 或 "2019年05月15日-2025年05月15日"
     * @return 数组：[起始日期, 截止日期]
     */
    private String[] parseValidPeriod(String validPeriod) {
        // 移除所有空格
        validPeriod = validPeriod.replace(" ", "");

        // 分割起始和结束日期
        String[] parts = new String[]{"", ""};

        if (validPeriod.contains("-")) {
            String[] dateParts = validPeriod.split("-");
            if (dateParts.length == 2) {
                // 格式化起始日期
                parts[0] = formatDateString(dateParts[0]);
                // 格式化截止日期
                parts[1] = formatDateString(dateParts[1]);
            }
        }

        return parts;
    }

    /**
     * 格式化日期字符串为 yyyy-MM-dd 格式
     */
    private String formatDateString(String dateStr) {
        try {
            // 如果是纯数字格式，如：20190515
            if (dateStr.matches("\\d{8}")) {
                SimpleDateFormat sdf = new SimpleDateFormat("yyyyMMdd");
                Date date = sdf.parse(dateStr);
                sdf.applyPattern("yyyy-MM-dd");
                return sdf.format(date);
            }
            // 如果是中文格式，如：2019年05月15日
            else if (dateStr.contains("年") && dateStr.contains("月") && dateStr.contains("日")) {
                return formatChineseDate(dateStr);
            }
            // 其他格式尝试直接转换
            else {
                // 尝试多种日期格式
                String[] patterns = {"yyyy.MM.dd", "yyyy/MM/dd", "yyyy-MM-dd"};
                for (String pattern : patterns) {
                    try {
                        SimpleDateFormat sdf = new SimpleDateFormat(pattern);
                        Date date = sdf.parse(dateStr);
                        sdf.applyPattern("yyyy-MM-dd");
                        return sdf.format(date);
                    } catch (Exception e) {
                        continue;
                    }
                }
                return dateStr; // 无法解析，返回原字符串
            }
        } catch (Exception e) {
            return dateStr; // 解析失败，返回原字符串
        }
    }
}
```

# 司机实名认证 OCR 识别

司机通过上传

- **身份证正面**、**反面照片**以及**本人手持身份证照片**
- **驾驶证主页、副本以及本人手持驾驶证照片**

来完成司机实名认证。

## 身份证正面识别

**实现思路：**

- **第一步：**微信小程序上传身份证正面照片到后端服务器。
- **第二步：**后端服务器进行 OCR 识别。识别可能成功，可能失败，如果失败直接抛出异常。识别成功后将信息放到 Map 集合。
- **第三步：**OCR 识别成功后，将身份证正面图片存储到腾讯云对象存储服务器中。可能成功，可能失败，如果失败直接抛出异常。
- **第四步：**存储成功后，调用腾讯云的数据万象服务，验证图片是否合法，如果合法就返回图片在腾讯云对象存储服务器上的临时 URL。如果不合法直接删除图片并抛出异常。
- **第五步：**将识别的信息 Map 和图片的临时 URL 封装为 Map，返回给小程序。
- **第六步：**小程序从返回的 json 中提取信息渲染页面。

### 编写 web 方法

在 `<font style="color:#000000;">bff-driver</font>`子系统中，编写 `<font style="color:#000000;">OcrController</font>`，完成：

1. 调用 ocr 服务，获取识别信息。
2. 将图片上传到腾讯云的对象存储服务器。
3. 调用数据万象验证图片合法性。
4. 获取图片的地址，并将地址保存到 result 中，返回给前端，前端将来使用这个地址生成图片的临时访问 URL。这个图片地址最终也是要保存到数据库当中，图片的路径像这样：`**<font style="color:#000000;">/driver/auth/cf2bb5b1f3ca419f9f2c2004957d6837.jpg</font>**`
5. 获取图片在腾讯云对象存储服务器上的临时 URL。用于当下小程序中图片的预览。
6. **返回识别的信息+图片路径+临时 URL 给前端小程序**。

```java
package com.example.zxds.bff.driver.controller;

import com.example.zxds.common.exception.ZxdsException;
import com.example.zxds.common.util.CosUtil;
import com.example.zxds.common.util.OcrUtil;
import com.example.zxds.common.util.R;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.tags.Tag;
import lombok.extern.slf4j.Slf4j;
import org.json.JSONObject;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import javax.annotation.Resource;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

@RestController
@Slf4j
@RequestMapping("/ocr")
@Tag(name = "OcrController", description = "OCR识别web接口")
public class OcrController {

    @Resource
    private OcrUtil ocrUtil;

    @Resource
    private CosUtil cosUtil;

    @PostMapping("/recognizeAndUpload")
    //@SaCheckLogin  // 测试的时候注释掉，测试完之后放开。
    @Operation(summary = "识别并上传文件")
    public R recognizeAndUpload(@RequestParam("file") MultipartFile file,
                                @RequestParam("module") String module,
                                @RequestParam("ocrType") String ocrType) {
        if (file.isEmpty()) {
            throw new ZxdsException("上传文件不能为空");
        }

        // 准备最终返回的结果
        Map<String, Object> result = new HashMap<>();

        // OCR识别
        if ("1".equals(ocrType)) {
            // 进行身份证正面识别
            JSONObject jsonObject = ocrUtil.recognizeIdCard(file, "front");
            Map<String, String> idCardFrontInfo = ocrUtil.extractFrontInfo(jsonObject);
            result.put("idCardFrontInfo", idCardFrontInfo);
        }

        // 将文件上传到腾讯云的对象存储服务器
        try {
            String path = null;
            if ("driverAuth".equals(module)) {
                path = "/driver/auth/";
            } else {
                throw new ZxdsException("module错误");
            }
            HashMap map = cosUtil.uploadPrivateFile(file, path);
            // 获取图片在腾讯云服务器上存储的路径
            String filePath = String.valueOf(map.get("path")); // 这个路径可能是这样的：/driver/auth/cf2bb5b1f3ca419f9f2c2004957d6837.jpg
            result.put("filePath", filePath); // 将这个路径存储到result并返回给前端，前端通过这个路径可以获取图片的临时URL。
            // 接下来立即获取一个临时URL给前端，5分钟有效，主要是用于小程序预览图片。
            String tempUrl = cosUtil.getPrivateFileUrl(String.valueOf(map.get("path")));
            result.put("tempUrl", tempUrl);
        } catch (IOException e) {
            log.error("文件上传到腾讯云错误", e);
            throw new ZxdsException("文件上传到腾讯云错误");
        }
        return R.ok(result);
    }

    @GetMapping("/image/temp")
    @Operation(summary = "获取临时图片访问URL")
    public R getTempImageUrl(@RequestParam String path) {
        // 验证路径安全性（防止路径遍历攻击）
        if (!path.startsWith("/driver/auth/")) {
            throw new ZxdsException("路径不合法");
        }

        String tempUrl = cosUtil.getPrivateFileUrl(path);
        return R.ok().put("tempUrl", tempUrl);
    }
}
```

```java
package com.example.zxds.bff.driver.controller;

import com.example.zxds.common.exception.ZxdsException;
import com.example.zxds.common.util.CosUtil;
import com.example.zxds.common.util.OcrUtil;
import com.example.zxds.common.util.R;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.tags.Tag;
import lombok.extern.slf4j.Slf4j;
import org.json.JSONObject;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import javax.annotation.Resource;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

@RestController
@Slf4j
@RequestMapping("/ocr")
@Tag(name = "OcrController", description = "OCR识别web接口")
public class OcrController {

    @Resource
    private OcrUtil ocrUtil;

    @Resource
    private CosUtil cosUtil;

    @PostMapping("/recognizeAndUpload")
    //@SaCheckLogin  // 测试的时候注释掉，测试完之后放开。
    @Operation(summary = "识别并上传文件")
    public R recognizeAndUpload(@RequestParam("file") MultipartFile file,
                                @RequestParam("module") String module,
                                @RequestParam("ocrType") String ocrType) {
        if (file.isEmpty()) {
            throw new ZxdsException("上传文件不能为空");
        }

        // 准备最终返回的结果
        Map<String, Object> result = new HashMap<>();

        // OCR识别
        if ("1".equals(ocrType)) {
            // 进行身份证正面识别
            JSONObject jsonObject = ocrUtil.recognizeIdCard(file, "front");
            Map<String, String> idCardFrontInfo = ocrUtil.extractFrontInfo(jsonObject);
            result.put("idCardFrontInfo", idCardFrontInfo);
        }else if("2".equals(ocrType)){
            JSONObject jsonObject = ocrUtil.recognizeIdCard(file, "back");
            Map<String, String> idCardBackInfo = ocrUtil.extractBackInfo(jsonObject);
            result.put("idCardBackInfo", idCardBackInfo);
        }

        // 将文件上传到腾讯云的对象存储服务器
        try {
            String path = null;
            if ("driverAuth".equals(module)) {
                path = "/driver/auth/";
            } else {
                throw new ZxdsException("module错误");
            }
            HashMap map = cosUtil.uploadPrivateFile(file, path);
            // 获取图片在腾讯云服务器上存储的路径
            String filePath = String.valueOf(map.get("path")); // 这个路径可能是这样的：/driver/auth/cf2bb5b1f3ca419f9f2c2004957d6837.jpg
            result.put("filePath", filePath); // 将这个路径存储到result并返回给前端，前端通过这个路径可以获取图片的临时URL。
            // 接下来立即获取一个临时URL给前端，5分钟有效，主要是用于小程序预览图片。
            String tempUrl = cosUtil.getPrivateFileUrl(String.valueOf(map.get("path")));
            result.put("tempUrl", tempUrl);
        } catch (IOException e) {
            log.error("文件上传到腾讯云错误", e);
            throw new ZxdsException("文件上传到腾讯云错误");
        }
        return R.ok(result);
    }

    @GetMapping("/image/temp")
    @Operation(summary = "获取临时图片访问URL")
    public R getTempImageUrl(@RequestParam String path) {
        // 验证路径安全性（防止路径遍历攻击）
        if (!path.startsWith("/driver/auth/")) {
            throw new ZxdsException("路径不合法");
        }

        String tempUrl = cosUtil.getPrivateFileUrl(path);
        return R.ok().put("tempUrl", tempUrl);
    }
}
```

## 提交实名认证信息

用户点击小程序页面的“保存信息”按钮之后，我们要先做前端验证，然后发起Ajax请求把实名信息包括证件照片地址提交给后端的Java程序。


大家注意按钮的`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">:disabled</font>`属性，司机未认证（1状态）和已认证（2状态），都是可以填写实名信息的并且提交的。但是如果司机的实名认证是审核中（3状态），那么司机是不能修改实名信息并且重新提交的。审核通过之后（2状态），那么司机是可以修改实名信息，然后重新提交审核请求的。

在`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">main.js</font>`文件中定义了很多前端验证的函数，例如验证`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">checkValidTel()</font>`函数是用来验证手机号码的，该函数需要我们传入两个参数：等待验证的数据、数据的名称（显示验证失败时候使用）

# 实现司机登录功能

前端小程序提供临时授权码 code，后端根据 code 获取 openId，在数据库中根据 openId 字段查询司机信息。

1. 没有查到信息，说明没有注册，提醒注册。
2. 查到信息后，还需要将 `<font style="color:#000000;">real_auth</font>`以及 `<font style="color:#000000;">archive</font>`字段返回，用于判断该用户是否已经实名认证，是否已经采集面部照片。

## 调试程序

1. **第一种情况：**正常登录。用户注册了，并且实名认证了，也进行了面部信息采集。直接跳转到工作台。
2. **第二种情况：**用户没有注册。提示用户先注册。（**如果数据库中有之前的测试数据，先删除掉。删除司机，钱包，设置。**）
3. **第三种情况：**用户注册了，但是没有实名认证，跳转到实名认证页面。（**把**`**<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">tb_driver</font>**`**表的**`**<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">real_auth</font>**`**字段设置成1，**`**<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">archive</font>**`**字段设置成0，然后去腾讯云人员库里面把司机面部信息删除掉**）
4. **第四种情况：**用户注册了，也实名认证了，但是没有录入面部信息，弹出提示框，用户可以选择录入面部信息，也可以选择不录入，如果不录入也可以跳转到工作台，只不过该司机不能接单。（**去腾讯云人员库把司机面部信息删除，再把**`**<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">td_driver</font>**`**表中的司机注册信息的**`**<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">archive</font>**`**字段设置成0**）

```javascript
clearHandle() {
    uni.vibrateShort({});
    uni.showModal({
        title: '提示消息',
        content: '清理本地缓存',
        success: function(resp) {
            if (resp.confirm) {
                uni.vibrateShort({});
                uni.showLoading({
                    title: '执行中'
                });
                //删除Storage中不必要的缓存
                let cache = uni.getStorageInfoSync();
                for (let key of cache.keys) {
                    if (key == 'token' || key == 'realAuth') {
                        continue;
                    }
                    uni.removeStorageSync(key); //删除不必要的缓存
                    console.log('删除Storage缓存成功');
                }

                //删除保存的临时文件
                uni.getSavedFileList({
                    success: function(resp) {
                        for (let one of resp.fileList) {
                            let path = one.filePath;
                            uni.removeSavedFile({
                                filePath: path,
                                success: function() {
                                    console.log('缓存文件删除成功');
                                }
                            });
                        }
                    }
                });
                setTimeout(function() {
                    uni.showToast({
                        title: '清理完毕'
                    });
                }, 500);
            }
        }
    });
},
```

```xml
<!--注意：mybatis中，查询结果中，如果某列是null，返回结果如果是map集合，则map集合中不会创建对应的key。因此要添加ifnull函数-->
<select id="searchDriverTodayBusinessData" parameterType="long" resultType="map">
    SELECT IFNULL(SUM(TIMESTAMPDIFF(HOUR,end_time, start_time)),0) AS duration,

    WHERE driver_id = #{driverId}
      AND `status` IN (5, 6, 7, 8)
      AND date = CURRENT_DATE
</select>
```

```java
import cn.hutool.core.map.MapUtil;
import com.example.zxds.odr.db.dao.OrderDao;
import com.example.zxds.odr.service.OrderService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.Map;

@Service
@RequiredArgsConstructor
public class OrderServiceImpl implements OrderService {

    private final OrderDao orderDao;

    @Override
    public Map<String, Object> searchDriverTodayBusinessData(long driverId) {
        Map<String, Object> result = orderDao.searchDriverTodayBusinessData(driverId);
        String duration = MapUtil.getStr(result, "duration");
        if (duration == null) {
            duration = "0";
        }
        result.replace("duration", duration);

        String income = MapUtil.getStr(result, "income");
        if (income == null) {
            income = "0.00";
        }
        result.replace("income", income);

        return result;
    }
}
```

```java
import cn.hutool.core.map.MapUtil;
import cn.hutool.json.JSONUtil;
import com.example.zxds.dr.db.dao.DriverSettingsDao;
import com.example.zxds.dr.service.DriverSettingsService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.Map;

@Service
@RequiredArgsConstructor
public class DriverSettingsServiceImpl implements DriverSettingsService {

    private final DriverSettingsDao driverSettingsDao;

    @Override
    public Map<String, Object> searchDriverSettings(long driverId) {
        String settings = driverSettingsDao.searchDriverSettings(driverId);
        Map<String, Object> map = JSONUtil.parseObj(settings).toBean(Map.class);
        boolean bool = MapUtil.getInt(map, "listenService") == 1;
        map.replace("listenService", bool);
        bool = MapUtil.getInt(map, "autoAccept") == 1;
        map.replace("autoAccept", bool);
        return map;
    }
}
```

### BFF 层 Feign 客户端的粒度设计原则

Feign 接口的划分应该遵循 **DDD（领域驱动设计）** 的思想，以**业务聚合根**为单位。

反对“物理映射”（下游 Controller 对上游 Feign 接口），提倡“逻辑映射”（按**业务领域/聚合根**划分 Feign 接口），以实现上下游解耦和业务内聚。

应该将属于同一个业务领域（Aggregate）的多个 Controller 接口，收敛到 BFF 层的一个 Feign Client 接口中。这样能最大程度地解耦上下游，提高系统的可维护性。

因为在`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">driver.vue</font>`页面中，有很多操作都需要重新加载页面分页数据的，例如条件查询、审批司机实名信息等等，所以我们应该把加载分页数据的代码给封装起来。

```javascript
async loadDataList() {
    let that = this;
    that.dataListLoading = true;
    let data = {
        pageIndex: that.pageIndex,
        pageSize: that.pageSize,
        name: that.dataForm.name || null,
        sex: that.dataForm.sex || null,
        tel: that.dataForm.tel || null,
        pid: that.dataForm.pid || null,
        realAuth: that.dataForm.realAuth || null,
        status: that.dataForm.status || null
    };

  let response = await axios.post(`${that.$baseUrl}driver/searchDriverByPage`,data, {
    headers: {
      token: localStorage.getItem("token")
    }
  });
  let result = response.data.result;
  let list = result.list;
  let status = {
      '1': '正常',
      '2': '禁用',
      '3': '降低接单'
  };
  let realAuth = {
      '1': '未认证',
      '2': '已认证',
      '3': '审核中'
  };
  for (let one of list) {
      one.status = status[one.status + ''];
      one.realAuth = realAuth[one.realAuth];
  }
  that.dataList = list;
  that.totalCount = Number(result.totalCount);
  that.dataListLoading = false;
},
```

调用`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">loadDataList()</font>`函数加载分页数据。

```javascript
created: function() {

}
```

```javascript
sizeChangeHandle(val) {

currentChangeHandle(val) {

},
```

在`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">tb_driver</font>`数据表里面，司机的证件地址写的是相对路径。当外部需要用到这些证件照片的时候，我们生成临时外网URL路径，超过规定时间就无法访问，起到保护司机证件隐私的目的。

![9c0096ba-734b-4683-ab02-5f4d4f97f63f.png](images/LCveb5qyvosTlFxd08AcuSfrnfd.png)

腾讯云对象存储服务有一个“生成预签名URL”的功能，可以对云端文件生成临时外网URL地址，并且含有签名字符串。当然了，这个签名字符串是有过期时间的，如果超过规定的时间，这个URL地址就不能使用了。预签名URL的文档（[https://cloud.tencent.com/document/product/436/35217](https://cloud.tencent.com/document/product/436/35217)）。

在`<font style="color:#000000;background-color:rgba(220, 240, 255, 0.3) !important;">CosUtil.java</font>`类中我已经封装好了生成预签名URL的函数：

```java
@Component
public class CosUtil {
    ……
    public String getPrivateFileUrl(String path) {
        COSClient client = getCosPrivateClient();
        GeneratePresignedUrlRequest request =
        new GeneratePresignedUrlRequest(bucketPrivate, path, HttpMethodName.GET);
        Date expiration = DateUtil.offsetMinute(new Date(), 5);  //设置临时URL有效期为5分钟
        request.setExpiration(expiration);
        URL url = client.generatePresignedUrl(request);
        client.shutdown();
        return url.toString();
    }
}
```

```java
    String idcardBack = MapUtil.getStr(map, "idcardBack");

    String drcardBack = MapUtil.getStr(map, "drcardBack");

    String idcardBackUrl = !idcardBack.isEmpty() ? cosUtil.getPrivateFileUrl(idcardBack) : "";
    String idcardHoldingUrl = !idcardHolding.isEmpty() ? cosUtil.getPrivateFileUrl(idcardHolding) : "";
    String drcardFrontUrl = !drcardFront.isEmpty() ? cosUtil.getPrivateFileUrl(drcardFront) : "";
    String drcardBackUrl = !drcardBack.isEmpty() ? cosUtil.getPrivateFileUrl(drcardBack) : "";
    String drcardHoldingUrl = !drcardHolding.isEmpty() ? cosUtil.getPrivateFileUrl(drcardHolding) : "";
    map.put("idcardFrontUrl", idcardFrontUrl);
    map.put("idcardBackUrl", idcardBackUrl);
    map.put("idcardHoldingUrl", idcardHoldingUrl);
    map.put("drcardFrontUrl", drcardFrontUrl);
```

```java
import com.example.zxds.common.exception.ZxdsException;
import com.example.zxds.common.util.MicroAppUtil;

import com.example.zxds.cst.service.CustomerService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.HashMap;
import java.util.Map;

@Service
@RequiredArgsConstructor
public class CustomerServiceImpl implements CustomerService {

    private final CustomerDao customerDao;

    private final MicroAppUtil microAppUtil;

    @Override
    @Transactional
    public String registerNewCustomer(Map<String, Object> param) {
        String code = MapUtil.getStr(param, "code");
        String openId = microAppUtil.getOpenId(code);
        Map<String, Object> tempParam = new HashMap<>() {{
            put("openId", openId);
        }};
        if (customerDao.hasCustomer(tempParam) != 0) {
            throw new ZxdsException("该微信无法注册");
        }

        long id = IdUtil.getSnowflake(1, 2).nextId();
        param.put("id", id);
        param.put("openId", openId);
        customerDao.registerNewCustomer(param);
        String customerId = customerDao.searchCustomerId(openId);
        return customerId;
    }
}
```

```java
@PostMapping("/login")
@Operation(summary = "登录系统")
public R login(@RequestBody @Valid LoginForm form) {
    Long customerId = customerService.login(form);
    if (customerId != null) {
        StpUtil.login(customerId);
        String token = StpUtil.getTokenInfo().getTokenValue();
        return R.ok().put("token", token);
    }
    return R.ok();
```

### 实现登录功能

```javascript
login() {
    let that = this;
    uni.login({
        provider: 'weixin',
        success: function(resp) {
            let code = resp.code;
            let data = {
                code: code
            };
            that.ajax(that.url.login, 'POST', data, function(resp) {
                if (!resp.data.hasOwnProperty('token')) {
                    that.$refs.uToast.show({
                        title: '请先注册',
                        type: 'error'
                    });
                } else {
                    let token = resp.data.token;
                    uni.setStorageSync('token', token);
                    that.$refs.uToast.show({
                        title: '登录成功',
                        type: 'success',
                        callback: function() {
                            uni.switchTab({
                                url: '../workbench/workbench'
                            });
                        }
                    });
                }
            });
        }
    });
}
```
