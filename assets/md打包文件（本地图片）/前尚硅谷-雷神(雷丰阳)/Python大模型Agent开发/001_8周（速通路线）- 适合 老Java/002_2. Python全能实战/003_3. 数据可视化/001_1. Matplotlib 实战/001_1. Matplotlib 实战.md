### 核心概念

Matplotlib 采用**层次化结构**：

- **Figure（画布）**：整个图形窗口，所有其他绘图元素都必须绘制在 Figure 上。
  - **包含多个子图** ：一个 Figure 可以包含任意数量的 Axes（子图），通过 `plt.subplots()` 或 `fig.add_subplot()` 创建。
  - **设置整体属性** ：
    - 画布大小：` fig.set_size_inches(10, 6)`
    - 背景颜色：` fig.set_facecolor('#f0f0f0')`
    - 分辨率（仅保存时生效）： `fig.dpi = 300`
  - **管理布局**** **：通过 `fig.tight_layout()` 或 `fig.subplots_adjust()` 调整子图间距。
  - **保存/显示** ：` fig.savefig('plot.png') `或 `plt.show()` 。

![image.png](images/Aovsbf1BKod3UjxAkCdc86Ncnnd.png)
- **Axes（坐标系）**：Axes 是 Figure 上的一个 独立绘图区域 ，相当于一个**"子图"**，包含自己的 X 轴、Y 轴和绘图元素
![image.png](images/LpATbI4K4ooZFYxn34scNdHJnDf.png)

  - **绘制图表** ：调用各类绘图方法，如:
    - `ax.plot()` （折线图）、 `ax.bar()` （柱状图）、 `ax.scatter()` （散点图）等。
  - **设置图表属性 **：
    - 标题： `ax.set_title('销售趋势')`
    - X/Y轴标签： `ax.set_xlabel('月份')` 、 `ax.set_ylabel('销售额')`
    - 图例： `ax.legend()`
    - 网格线： `ax.grid(True)`
  - **坐标轴范围 **： `ax.set_xlim(0, 12) `、 `ax.set_ylim(0, 10000)`
- **Axis（坐标轴）**：X轴和Y轴，控制刻度与标签；
  - **刻度设置 **：
    - 自动/手动刻度： `ax.xaxis.set_ticks([1, 3, 5, 7])`
    - 刻度标签格式： `ax.xaxis.set_major_formatter(plt.FuncFormatter(lambda x, _: f'{x}月'))`
  - **标签设置** ：
    - 轴标题： `ax.xaxis.set_label_text('月份')` （等价于 ax.set_xlabel() ）
    - 刻度标签旋转： `ax.xaxis.set_tick_params(rotation=45)`
  - **刻度样式** ：
    - 刻度线长度/宽度： `ax.yaxis.set_tick_params(length=5, width=2)`
  - **隐藏刻度**： `ax.xaxis.set_visible(False)`
  - **刻度的位置由一个 **`Locator 对象`**决定，而刻度标签字符串由一个 **`Formatter `**格式化**
- **Artist**：所有可见对象；是 Matplotlib 中 所有可见元素的抽象基类 ，包括 Figure、Axes、Axis 中的具体可见部分（如**线条**、**文本**、**图例**、**网格**等）。任何在图表上“可见”的元素都是 Artist 的实例。
  - **样式定制** ：所有 Artist 都可自定义颜色、大小、线宽、透明度等属性。
  - **层次控制 **：通过 zorder 参数控制绘制顺序（值越大越上层）。
  - **可见性控制 **： `artist.set_visible(True/False) `控制元素是否显示。

### 两种绘图接口

Matplotlib 提供了两种绘图接口，理解它们的区别对于编写高质量代码至关重要。

#### pyplot 接口（状态机接口）

```python
import matplotlib.pyplot as plt

# pyplot 接口：隐式操作"当前"图表 
plt.plot([1, 2, 3, 4], [1, 4, 2, 3])
plt.title('简单折线图')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.show()
```

- 类似 **MATLAB **风格，简单直观
- 自动管理 `Figure `和 `Axes`
- 适合快速**绘制单个图表**
- 隐式操作"当前活动"的图表

#### 面向对象接口（推荐）

```python
import matplotlib.pyplot as plt

# 面向对象接口：显式创建和操作对象
fig, ax = plt.subplots()
ax.plot([1, 2, 3, 4], [1, 4, 2, 3])
ax.set_title('简单折线图')
ax.set_xlabel('X轴')
ax.set_ylabel('Y轴')
plt.show()
```

- 显式创建 `Figure `和 `Axes `对象
- **精确控制每个图表元素**
- 适合**复杂布局**和**多子图**
- 代码更清晰、可维护性强

#### 接口转换对照

**记忆技巧**：

- pyplot 接口：`plt.xxx()`
- 面向对象接口：`ax.xxx()` 或 `ax.set_xxx()`

---

> **💡 总结：pyplot 接口不能完全替代面向对象接口。对于专业开发和复杂项目**
> 
> **强烈推荐使用面向对象接口！**

    # wedges: 饼图的扇形对象
    # texts: 标签对象
    # autotexts: 自动百分比标签对象
    explode = [0.05 if i == 0 else 0 for i in range(len(category_sales))]

**散点图的核心要素：**

- **点的位置**：表示两个变量的数值

- **点的颜色**：可表示第三个变量（分类或连续）

- **点的大小**：可表示第四个变量（气泡图）

- **点的分布模式**：揭示变量间的关系

> **如何解读散点图：**
> 
> 1. **相关性判断**：
> 
> - 正相关：点从左下到右上分布
> - 负相关：点从左上到右下分布
> - 无相关：点随机分布
> 
> 2. **聚类识别**：观察是否存在明显的点群
> 
> 3. **异常值发现**：识别远离主体的离群点
> 
> 4. **趋势线**：添加回归线判断线性关系强度
> 
> 5. **密度分析**：点密集区域表示数据集中

import pandas as pd
def plot03():
    # 准备数据
    df_sales['年龄段'] = pd.cut(df_sales['客户年龄'], 
        bins=[0, 18, 30, 45, 60, 100],
        labels=['18岁以下','18-30岁','30-45岁','45-60岁','60岁以上'])
   
    age_sales = df_sales.pivot_table(
        index=['年龄段','客户性别'],
        values=['销售额','订单号'],
        aggfunc={
            '销售额': 'mean',
            '订单号': 'count'
        },
        observed=False
    ).reset_index()
    age_sales.columns = ['年龄段','客户性别','订单数','销售额']

    
    fig,ax = plt.subplots(figsize=(12, 6))

    # 绘制男性气泡图
    male_data = age_sales[age_sales['客户性别']== '男']
    print(male_data)
    ax.scatter(x = male_data['年龄段'],
               y = male_data['销售额'],
               s = male_data['订单数'],
               c = 'blue',
               label='男性',
               alpha=0.5)

    # 绘制女性气泡图
    female_data = age_sales[age_sales['客户性别']== '女']
    ax.scatter(x = female_data['年龄段'],
               y = female_data['销售额'],
               s = female_data['订单数'],
               c = 'red',

### 箱线图与小提琴图

https://matplotlib.org/stable/gallery/statistics/boxplot_demo.html

> 假设下图是采样了《金融行业》每个国家10000个员工的薪资

![image.png](images/Ck22byXPpofQtIxvieicbDNfn0e.png)

**箱线图的核心要素：**

- **箱体**：表示数据的四分位数范围（IQR，25%-75%）

- **中线**：中位数（50%分位数）

- **均值点**：数据的平均值（可选显示）

- **须线**：延伸到1.5倍IQR范围内的最远数据点

- **异常点**：超出须线范围的离群值

- **显著性标签：**表示 两组或多组数据之间的差异是否具有统计学意义 （即差异是由随机误差引起的，还是真实存在的）。

**如何解读箱线图：**

1. **中位数位置**：箱体内中线的位置

2. **数据离散度**：箱体越长，数据越分散

3. **偏态判断**：

- 中线偏上：左偏（负偏）
- 中线偏下：右偏（正偏）

4. **异常值识别**：须线外的点为潜在异常值

5. **组间比较**：比较不同组的箱体位置和大小

#### **savefig() 函数参数详解**

根据不同的使用场景，常用的dpi值如下：

- 默认值 ：通常为 100 或 80 （Matplotlib默认设置，适合屏幕显示）
- 屏幕显示 ： 100-150 （平衡清晰度和文件大小）
- 高清图像 ： 300 （常用的高清输出，适合演示文稿或网页）
- 打印输出 ： 300-600 （印刷级质量，适合期刊论文或宣传材料）
- 高精度印刷 ： 600-1200 （专业印刷需求，如书籍出版）

color2 = '#E74C3C'
ax1_twin.set_ylabel('利润率（%）', color=color2, fontsize=12, fontweight='bold')

                      color=color2, linewidth=2.5, linestyle='--',
