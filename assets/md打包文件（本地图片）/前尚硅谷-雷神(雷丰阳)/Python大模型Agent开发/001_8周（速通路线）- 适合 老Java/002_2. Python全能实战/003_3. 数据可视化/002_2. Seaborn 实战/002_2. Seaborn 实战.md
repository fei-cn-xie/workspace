## 关系图表

> 关系图表用于展示两个或多个变量之间的关系。

### 散点图（scatterplot）

> **用途：** 展示两个连续变量之间的关系，发现数据中的模式和趋势
> 
> **什么时候用散点图？**
> 
> - 想知道两个数值之间有没有关系（比如：身高和体重、学习时间和成绩）
> - 想找出异常值（离群点）
> - 想看数据的分布模式

#### **案例：使用 tips 数据集（餐厅小费数据）**

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 设置中文显示
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 加载数据
tips = sns.load_dataset('tips')

# 先看看数据长什么样
print(tips.head())
print(f"\n数据说明：")
print(f"- total_bill: 账单总额（美元）")
print(f"- tip: 小费金额（美元）")
print(f"- sex: 性别")
print(f"- time: 用餐时间（午餐/晚餐）")
print(f"- size: 用餐人数")

# 基础散点图
plt.figure(figsize=(10, 6))
sns.scatterplot(data=tips, x='total_bill', y='tip')
plt.title('账单总额 vs 小费金额')
plt.xlabel('账单总额（美元）')
plt.ylabel('小费金额（美元）')
plt.show()
```

**📊 如何看懂这个图？**

1. **横轴（X轴）**：账单总额，从左到右金额递增
2. **纵轴（Y轴）**：小费金额，从下到上金额递增
3. **每个点**：代表一次用餐记录
4. **整体趋势**：
  - 点从左下到右上分布 → 账单越高，小费越多（正相关）
  - 如果点很分散 → 关系不明显
  - 如果点很集中 → 关系很强

**💡 从这个图能看出什么？**

- ✅ 账单总额和小费金额呈正相关（账单越高，小费越多）
- ✅ 大部分账单在 10-30 美元之间
- ✅ 小费一般在 2-6 美元之间
- ✅ 有几个"大方"的顾客（右上角的点）

### 线图 (lineplot)

> **用途：** 展示数据随时间或顺序的变化趋势
> 
> **什么时候用线图？**
> 
> - 展示时间序列数据（股票价格、气温变化、销售趋势）
> - 观察数据的变化趋势（上升、下降、波动）
> - 比较多组数据的趋势

#### **案例：使用 fmri 数据集（脑成像信号数据）**

```python
# 加载数据
fmri = sns.load_dataset('fmri')

# 先看看数据
print(fmri.head(10))
print(f"\n数据说明：")
print(f"- timepoint: 时间点（0-17秒）")
print(f"- signal: 脑部信号强度")
print(f"- event: 事件类型（stim=刺激，cue=提示）")
print(f"- region: 脑区（parietal=顶叶，frontal=额叶）")

# 基础线图
plt.figure(figsize=(12, 6))
sns.lineplot(data=fmri, x='timepoint', y='signal', hue='event')
plt.title('脑成像信号随时间变化')
plt.xlabel('时间点（秒）')
plt.ylabel('信号强度')
plt.axhline(0, color='gray', linestyle='--', alpha=0.5)  # 添加基线
plt.show()
```

**📊 如何看懂这个线图？**

1. **横轴（X轴）**：时间点，从 0 秒到 17 秒
2. **纵轴（Y轴）**：信号强度，正值表示激活，负值表示抑制
3. **线条**：连接各时间点的平均信号值
4. **阴影区域**：置信区间（表示数据的不确定性）
  - 阴影越窄 → 数据越稳定
  - 阴影越宽 → 数据波动越大

**💡 从这个图能看出什么？**

- ✅ 橙色线（stim刺激）：在 5-10 秒达到峰值，说明刺激后大脑有明显反应
- ✅ 蓝色线（cue提示）：信号变化较小，说明提示的影响较弱
- ✅ 两条线在 0-3 秒都接近 0，说明反应有延迟（符合生理规律）
- ✅ 15 秒后信号回落，说明刺激效果消退

#### **进阶：多维度线图**

```python
# 添加更多维度：不同脑区的信号
plt.figure(figsize=(14, 6))
sns.lineplot(data=fmri, x='timepoint', y='signal',

             style='region',     # 线型区分脑区
             markers=True,       # 显示数据点
             dashes=False)       # 不使用虚线
plt.title('不同脑区对不同事件的信号响应')
plt.xlabel('时间点（秒）')
plt.ylabel('信号强度')
plt.axhline(0, color='gray', linestyle='--', alpha=0.3)
plt.legend(title='事件类型 / 脑区', bbox_to_anchor=(1.05, 1))
plt.tight_layout()
plt.show()
```

**📊 如何看懂多维度线图？**

1. **颜色（hue）**：
  - 橙色 = 刺激事件（stim）
  - 蓝色 = 提示事件（cue）
2. **线型（style）**：
  - 实线 = 顶叶（parietal）
  - 虚线 = 额叶（frontal）
3. **标记点（markers）**：
  - 圆点/方块 = 实际测量的数据点
  - 帮助识别数据密度

**💡 从这个图能看出什么？**

- ✅ **顶叶对刺激反应最强**：橙色实线在 5-10 秒达到最高峰（约 0.4）
- ✅ **额叶反应较弱**：虚线的峰值明显低于实线
- ✅ **提示事件影响小**：蓝色线（cue）几乎没有明显波动，说明提示不足以激活大脑
- ✅ **反应有延迟**：所有线在 0-3 秒都接近 0，说明大脑需要时间处理刺激
- ✅ **信号衰减**：15 秒后所有信号回落到基线，说明刺激效果消退
- ✅ **脑区差异**：顶叶（实线）比额叶（虚线）对刺激更敏感，可能顶叶负责感知处理
- ✅ **综合结论**：刺激事件主要激活顶叶，提示事件几乎无效，反应有 3 秒延迟

分类图表用于展示分类变量与数值变量之间的关系。

### 条形图 (barplot)

> **用途：** 比较不同类别的平均值，自动显示置信区间
> 
> **什么时候用条形图？**
> 
> - 比较不同组的平均值（各班级平均分、各部门平均工资）
> - 展示分类数据的统计结果
> - 需要看到数据的不确定性（置信区间）
> 
> **⚠️ 注意：** 条形图显示的是**平均值**，不是总和！

#### **案例：使用 titanic 数据集（泰坦尼克号乘客数据）**

```python
# 加载数据
titanic = sns.load_dataset('titanic')

# 先看看数据
print(titanic.head())
print(f"\n数据说明：")
print(f"- class: 舱位等级（First=头等舱，Second=二等舱，Third=三等舱）")
print(f"- fare: 票价（英镑）")
print(f"- sex: 性别")
print(f"- survived: 是否生还（0=否，1=是）")
print(f"- age: 年龄")

# 基础条形图
plt.figure(figsize=(10, 6))
sns.barplot(data=titanic, x='class', y='fare', hue='sex')
plt.title('不同舱位的平均票价（按性别分组）')
plt.xlabel('舱位等级')
plt.ylabel('平均票价（英镑）')
plt.legend(title='性别', labels=['女性', '男性'])
plt.show()
```

**📊 如何看懂这个条形图？**

1. **柱子的高度**：代表该组的**平均值**
  - 头等舱女性平均票价约 106 英镑
  - 头等舱男性平均票价约 67 英镑
  - 三等舱平均票价约 13 英镑
2. **黑色竖线（误差线）**：95% 置信区间
  - 线越短 → 数据越稳定，平均值越可靠
  - 线越长 → 数据波动大，平均值不太稳定
  - 意思：真实平均值有 95% 概率在这个范围内
3. **颜色（hue）**：
  - 蓝色 = 女性
  - 橙色 = 男性
  - 同一舱位的两个柱子方便对比

**💡 从这个图能看出什么？**

- ✅ 头等舱票价最贵，三等舱最便宜（符合常识）
- ✅ 头等舱女性票价比男性贵 50% 以上！（可能女性带更多行李或有随从）
- ✅ 二等舱和三等舱的性别差异不大
- ✅ 头等舱的误差线较长，说明票价差异大（有人买便宜票，有人买豪华套房）

#### 什么是置信区间？

**置信区间（Confidence Interval, CI）** 是统计学中用来估计总体参数范围的一个区间，它表示我们对估计值的"信心程度"。

**核心概念：**

- **定义**：在重复抽样的情况下，有 X% 的概率真实值会落在这个区间内
- **常用值**：95% 置信区间（最常用）、99% 置信区间、68% 置信区间
- **意义**：区间越窄，估计越精确；区间越宽，不确定性越大

**直观理解：**

假设你想知道全国成年人的平均身高，但不可能测量所有人，只能抽样调查：

- 样本均值：170cm
- 95% 置信区间：[168cm, 172cm]
- 解读：我们有 95% 的把握，真实的全国平均身高在 168-172cm 之间

##### 代码演示

```python
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset('tips')

# 1. 条形图中的置信区间（默认 95%）
plt.figure(figsize=(10, 6))
sns.barplot(data=tips, x='day', y='total_bill')
plt.title('每天的平均账单（带 95% 置信区间）')
plt.show()
# 黑色竖线表示置信区间：真实均值有 95% 概率在这个范围内

# 2. 线图中的置信区间（阴影区域）
fmri = sns.load_dataset('fmri')
plt.figure(figsize=(10, 6))
sns.lineplot(data=fmri, x='timepoint', y='signal', ci=95)
plt.title('信号随时间变化（阴影为 95% 置信区间）')
plt.show()
# 阴影区域表示置信区间：真实趋势有 95% 概率在这个范围内

# 3. 自定义置信区间
plt.figure(figsize=(12, 5))

# 99% 置信区间（更宽，更保守）
plt.subplot(1, 3, 1)
sns.barplot(data=tips, x='day', y='total_bill', ci=99)
plt.title('99% 置信区间（更宽）')

# 95% 置信区间（标准）
plt.subplot(1, 3, 2)
sns.barplot(data=tips, x='day', y='total_bill', ci=95)
plt.title('95% 置信区间（标准）')

# 68% 置信区间（更窄，不太保守）
plt.subplot(1, 3, 3)
sns.barplot(data=tips, x='day', y='total_bill', ci=68)
plt.title('68% 置信区间（更窄）')

plt.tight_layout()
plt.show()

# 4. 使用标准差代替置信区间
plt.figure(figsize=(10, 6))
sns.lineplot(data=fmri, x='timepoint', y='signal', ci='sd')
plt.title('使用标准差表示数据分散程度')
plt.show()

# 5. 关闭置信区间
plt.figure(figsize=(10, 6))
sns.barplot(data=tips, x='day', y='total_bill', ci=None)
plt.title('不显示置信区间')
plt.show()
```

##### **置信区间参数说明：**

**置信区间 vs 标准差：**

```python
import numpy as np

# 模拟数据
np.random.seed(42)
data = pd.DataFrame({
    'group': ['A'] * 100 + ['B'] * 100,
    'value': np.concatenate([
        np.random.normal(10, 2, 100),  # A组：均值10，标准差2
        np.random.normal(12, 3, 100)   # B组：均值12，标准差3
    ])
})

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# 95% 置信区间（估计均值的范围）
sns.barplot(data=data, x='group', y='value', ci=95, ax=axes[0])
axes[0].set_title('95% 置信区间\n（真实均值的可能范围）')

# 标准差（数据的分散程度）
sns.barplot(data=data, x='group', y='value', errorbar='sd', ax=axes[1])
axes[1].set_title('标准差\n（数据的分散程度）')

# 标准误（均值估计的精确度）
sns.barplot(data=data, x='group', y='value', errorbar='se', ax=axes[2])
axes[2].set_title('标准误\n（均值估计的精确度）')

plt.tight_layout()
plt.show()
```

**关键区别：**

**实际应用建议：**

1. **比较组间差异**：使用 95% 置信区间（默认）
2. **展示数据分散**：使用标准差（`ci='sd'` 或 `errorbar='sd'`）
3. **样本量很小**：考虑使用 `ci=None` 或显示原始数据点
4. **科学出版**：通常使用 95% 置信区间
5. **探索性分析**：可以尝试不同的 ci 值观察稳定性

### 箱线图 (boxplot)

> **用途：** 展示数据分布的五数概括，快速识别异常值
> 
> **什么是箱线图？** 
> 箱线图用一个"盒子"和"胡须"来总结数据分布，是统计学中最常用的图表之一。

**箱线图的组成部分：**

```python
        异常值 ●
          |
    ——————┬——————  最大值（上边缘）
          |
    ┌─────┴─────┐
    │           │
    │     ━━━   │  中位数（Q2，50%）
    │           │
    └─────┬─────┘
          |
    ——————┴——————  最小值（下边缘）
          |
        异常值 ●

盒子上边缘 = Q3（75%分位数）
盒子下边缘 = Q1（25%分位数）
盒子高度 = IQR（四分位距）= Q3 - Q1
胡须长度 = 1.5 × IQR
超出胡须的点 = 异常值
```

**什么时候用箱线图？**

- 对比多组数据的分布
- 快速发现异常值（离群点）
- 了解数据的集中程度和对称性
- 数据量较大时（如果数据少，直接看散点图更好）

#### **案例：使用 tips 数据集**

```python
tips = sns.load_dataset('tips')

plt.xlabel('星期几')
plt.ylabel('账单总额（美元）')
plt.legend(title='用餐时间', labels=['晚餐', '午餐'])
plt.show()
```

**📊 如何看懂这个箱线图？**

**以周日晚餐为例：**

1. **盒子的位置**：
  - 盒子底部（Q1）≈ 15 美元：25% 的账单低于 15 美元
  - 盒子中间的线（中位数）≈ 20 美元：一半账单低于 20 美元
  - 盒子顶部（Q3）≈ 28 美元：75% 的账单低于 28 美元
2. **盒子的高度**：
  - 高度 = IQR = 28 - 15 = 13 美元
  - 盒子越高 → 数据越分散
  - 盒子越矮 → 数据越集中
3. **胡须（竖线）**：
  - 上胡须延伸到约 40 美元
  - 下胡须延伸到约 8 美元
  - 表示"正常"数据的范围
4. **异常值（点）**：
  - 超过 40 美元的点是异常值
  - 可能是大桌聚餐或特殊情况

**💡 从这个图能看出什么？**

- ✅ 周六和周日的账单普遍更高（盒子位置更高）
- ✅ 晚餐账单比午餐高（橙色盒子在蓝色上方）

- ✅ 周日有几个"大单"（异常值点），可能是家庭聚餐
- ✅ 周五账单最集中（盒子最矮），说明消费比较稳定

### 小提琴图 (violinplot)

- 数据量较大时（数据少用箱线图更好）

### 条带图 (stripplot)

**用途：** 展示所有数据点，类似一维散点图

> **什么是条带图？**
> 条带图把所有数据点沿着一条线（条带）显示出来，让你看到每一个数据点的位置。
> 
> **条带图 vs 蜂群图：**
> 
> - **条带图**：点可能重叠，需要加抖动（jitter）
> - **蜂群图**：点自动调整位置不重叠，但数据量大时很慢
> 
> **什么时候用条带图？**
> 
> - 数据量中等（100-1000 个点）
> - 想看到所有原始数据点
> - 数据量太大，蜂群图太慢时
> - 结合箱线图或小提琴图使用

#### **案例：使用 tips 数据集**

```python
# 基础条带图
plt.figure(figsize=(10, 6))
sns.stripplot(data=tips, x='day', y='total_bill', hue='time', dodge=True)
plt.title('账单分布（条带图）')
plt.xlabel('星期几')
plt.ylabel('账单总额（美元）')
plt.legend(title='用餐时间', labels=['午餐', '晚餐'])
plt.show()
```

**📊 如何看懂条带图？**

1. **点的位置**：
  - 横向位置 = 类别（星期几）
  - 纵向位置 = 数值（账单金额）
  - 每个点 = 一条真实记录
2. **dodge=True 的效果**：
  - 不同颜色的点左右错开
  - 蓝色点（午餐）在左边
  - 橙色点（晚餐）在右边
  - 方便对比两组数据
3. **点的重叠**：
  - 点重叠在一起 = 有多个相同的值
  - 点很密集 = 数据集中在这个范围

**💡 从这个图能看出什么？**

- ✅ **周四只有午餐**：只有蓝色点，没有橙色点
- ✅ **晚餐账单更高**：橙色点（晚餐）普遍比蓝色点（午餐）更高
- ✅ **周末数据多**：周六和周日的点最密集
- ✅ **异常值明显**：最上面的几个孤立点很容易发现（40+ 美元的大单）
- ✅ **数据分布**：能看到大部分账单在 10-25 美元之间
- ✅ **午餐更集中**：蓝色点的范围更窄，晚餐的范围更宽

**📊 什么是 jitter（抖动）？**

- 更容易看到数据的密度

**💡 从这个图能看出什么？**

- ✅ **透明度帮助**：alpha=0.5 让重叠的点颜色更深，显示密度
- ✅ **周日最密集**：点最多，颜色最深
- ✅ **分布形状**：能看出数据的整体形状（类似直方图的效果）

### 蜂群图 (swarmplot)

> **用途：** 展示所有数据点且不重叠，像蜜蜂聚集一样
> 
> **什么是蜂群图？**

> **什么时候用蜂群图？**
> 
> - 数据量不太大（<1000 个点）
> - 想看到每一个数据点
> - 想看数据的密度分布
> - 结合箱线图使用效果更好

### 分类图组合 (catplot)

> **用途：** 在多个子图（分面）中展示分类数据，方便对比不同组的统计特征
> 
> **什么是 catplot？**
> catplot 是 categorical plot（分类图）的缩写，它可以自动创建多个子图，在每个子图中显示不同组的分类数据分析。
> 
> **catplot vs 单个分类图：**
> 
> - **单个图**：只能看一个或几个组的对比
> - **catplot**：可以同时看多个组的对比，自动排列成网格

**catplot 支持的图表类型：**

- `'strip'` - 条带图
- `'swarm'` - 蜂群图
- `'box'` - 箱线图
- `'violin'` - 小提琴图
- `'bar'` - 条形图
- `'point'` - 点图

**什么时候用 catplot？**

- 需要对比多个类别的统计特征
- 数据有多个分组维度（比如：不同时间 × 不同地区）
- 想要系统地展示所有组合的对比

#### **案例：使用 exercise 数据集**

```python

            col='diet', kind='box', height=4)
plt.suptitle('不同饮食方案下的脉搏变化', y=1.02)
plt.show()
```

**📊 如何看懂这个 catplot？**

1. **整体布局**：
  - 左图 = 低脂饮食组（low fat）
  - 右图 = 无脂饮食组（no fat）
  - `col='diet'` = 按饮食方案分列
2. **每个子图内**：
  - X轴 = 测量时间（1分钟、15分钟、30分钟）
  - Y轴 = 脉搏（次/分钟）
  - 不同颜色 = 不同运动类型（休息、步行、跑步）
  - 箱线图显示分布
3. **箱线图含义**：
  - 盒子 = 四分位距（IQR）
  - 中线 = 中位数
  - 胡须 = 数据范围
  - 点 = 异常值

**💡 从这个图能看出什么？**

- ✅ **跑步脉搏最高**：绿色箱子（running）明显高于其他颜色
- ✅ **脉搏逐渐下降**：从 1分钟到 30分钟，所有箱子都在下降（心率恢复）

- ✅ **跑步恢复最慢**：绿色箱子在 30分钟后仍然较高（约 100），说明跑步后心率恢复需要更长时间
- ✅ **步行适中**：橙色箱子（walking）介于休息和跑步之间

## 分布图表

分布图表用于展示单个或多个变量的分布特征。

### 直方图 (histplot)

> **用途：** 展示数值变量的分布情况，看数据集中在哪里
> 
> **什么是直方图？**
> 直方图把数据分成若干个"箱子"（bins），统计每个箱子里有多少数据。就像把学生成绩分成 0-10分、10-20分...来统计每个分数段有多少人。
> 
> **直方图 vs 条形图的区别：**
> 
> - **直方图**：横轴是连续数值（身高、体重、成绩），柱子之间没有间隙
> - **条形图**：横轴是离散类别（性别、专业、城市），柱子之间有间隙
> 
> **什么时候用直方图？**
> 
> - 了解数据的分布形状（正态分布？偏态分布？）
> - 找出数据的集中趋势（大部分数据在哪里？）
> - 发现异常值和数据范围

#### **案例：使用 penguins 数据集（企鹅数据）**

```python
penguins = sns.load_dataset('penguins')

# 先看看数据

print(f"- flipper_length_mm: 鳍长（毫米）")
print(f"- body_mass_g: 体重（克）")
print(f"- island: 所在岛屿")

plt.ylabel('企鹅数量')

            linestyle='--', label=f'平均值: {penguins["flipper_length_mm"].mean():.1f}mm')
plt.legend()
plt.show()
```

**📊 如何看懂这个直方图？**

1. **横轴（X轴）**：鳍长，从 170mm 到 230mm
2. **纵轴（Y轴）**：该长度范围内的企鹅数量
3. **柱子高度**：数量越多，柱子越高

**💡 从这个图能看出什么？**

- ✅ 大部分企鹅鳍长在 180-220mm 之间
- ✅ 有两个"峰"（双峰分布）：
  - 第一个峰在 190mm 左右
  - 第二个峰在 215mm 左右
- ✅ **推测**：可能有两种体型的企鹅（实际上是不同物种）
- ✅ 平均值约 201mm（红色虚线）

### 经验累积分布图 (ecdfplot)

> **用途：** 展示累积分布函数，看有多少比例的数据小于某个值
> 
> **什么是 ECDF（经验累积分布函数）？**
> ECDF 图显示"小于等于某个值的数据占总数的百分比"。比如：体重小于等于 4000g 的企鹅占 60%。
> 
> **ECDF vs 直方图：**
> 
> - **直方图**：显示每个区间有多少数据（频数）
> - **ECDF**：显示小于等于某个值的数据比例（累积）
> 
> **什么时候用 ECDF？**
> 
> - 想知道某个值在数据中的位置（比如：我的成绩超过了多少人？）
> - 对比不同组的分布（不受 bins 选择影响）
> - 数据量较小时（直方图可能不够平滑）
> - 需要精确的百分位数信息

#### **案例：使用 penguins 数据集**

```python
# 基础 ECDF 图
plt.figure(figsize=(10, 6))
sns.ecdfplot(data=penguins, x='body_mass_g', hue='species')
plt.title('企鹅体重的累积分布')
plt.xlabel('体重（克）')
plt.ylabel('累积比例')
plt.axhline(0.5, color='gray', linestyle='--', alpha=0.5, label='中位数线（50%）')
plt.axhline(0.25, color='gray', linestyle=':', alpha=0.3)
plt.axhline(0.75, color='gray', linestyle=':', alpha=0.3)
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

**📊 如何看懂 ECDF 图？**

1. **横轴（X轴）**：体重值，从小到大
2. **纵轴（Y轴）**：累积比例，从 0 到 1（或 0% 到 100%）
3. **曲线的含义**：
  - 曲线上的每个点 (x, y) 表示：有 y% 的数据 ≤ x
  - 曲线从左下到右上递增
  - 曲线越陡 = 数据越集中
  - 曲线越平缓 = 数据越分散
4. **关键位置**：
  - y = 0.25 的位置 → Q1（第一四分位数，25%分位数）
  - y = 0.50 的位置 → 中位数（50%分位数）
  - y = 0.75 的位置 → Q3（第三四分位数，75%分位数）

### 地毯图 (rugplot)

> **用途：** 在坐标轴上显示每个数据点的精确位置
> 
> **什么是地毯图？**
> 
> 地毯图在坐标轴边缘画出一条条短线，每条线代表一个数据点，像地毯的流苏一样。
> 
> **地毯图的作用：**
> 
> - 显示数据的真实分布（不是估计，而是实际位置）
> - 结合其他图表使用，提供原始数据参考
> - 发现数据的聚集和空白区域
> - 数据量不太大时（<1000）效果最好
> 
> **什么时候用地毯图？**
> 
> - 结合核密度图或直方图，验证分布估计是否准确
> - 数据量适中（太多会重叠成一团）
> - 想看到每个数据点的实际位置

#### **案例：使用 tips 数据集**

```python
tips = sns.load_dataset('tips')

# 结合核密度图和地毯图
plt.figure(figsize=(10, 6))
sns.kdeplot(data=tips, x='total_bill', fill=True, color='skyblue', alpha=0.5)
sns.rugplot(data=tips, x='total_bill', height=0.05, color='red', alpha=0.5)
plt.title('账单分布（核密度 + 地毯图）')
plt.xlabel('账单总额（美元）')
plt.ylabel('密度')
plt.show()
```

**📊 如何看懂地毯图？**

1. **短线的位置**：
  - 每条红色短线 = 一个真实的数据点
  - 横向位置 = 该数据点的值
  - 纵向位置 = 固定在 X 轴上
2. **短线的密度**：
  - 短线密集的地方 = 数据点多
  - 短线稀疏的地方 = 数据点少
  - 没有短线的地方 = 没有数据
3. **与核密度图的关系**：
  - 蓝色曲线（KDE）= 平滑的估计
  - 红色短线（rug）= 真实的数据点
  - 短线密集的地方，KDE 曲线应该更高

**💡 从这个图能看出什么？**

- ✅ **数据集中在 10-25 美元**：这个区域的红色短线最密集
- ✅ **KDE 估计准确**：蓝色曲线的峰值确实在短线最密集的地方
- ✅ **有几个大额账单**：右侧（40-50 美元）有几条孤立的短线
- ✅ **没有极小值**：左侧（<5 美元）没有短线，说明没有特别便宜的账单
- ✅ **数据量可见**：能大致数出有 200+ 条短线（244 条记录）

- 调整 `alpha` 参数避免短线太深或太浅
- 调整 `height` 参数控制短线长度

### 分布图组合 (displot)

> **用途：** 在多个子图（分面）中展示分布，方便对比不同组的分布特征
> 
> **什么是 displot？**
> displot 是 distribution plot（分布图）的缩写，它可以自动创建多个子图，在每个子图中显示不同组的分布。
> 
> **displot vs 单个分布图：**
> 
> - **单个图**：只能看一个或几个组的分布
> - **displot**：可以同时看多个组的分布，自动排列成网格
> 
> **什么时候用 displot？**
> 
> - 需要对比多个类别的分布（比如：不同产品、不同地区、不同时间段）
> - 数据有多个分组维度
> - 想要系统地展示所有组合的分布

## 回归图表

回归图表用于展示变量之间的线性或非线性关系。

### 回归图 (regplot)

> **用途：** 展示两个变量的线性回归关系，自动拟合回归线
> 
> **什么是回归图？**
> 回归图在散点图的基础上，添加一条**"最佳拟合线"**（回归线），显示两个变量之间的趋势关系。
> 
> **回归图 vs 散点图：**
> 
> - **散点图**：只显示数据点，需要自己判断关系
> - **回归图**：显示数据点 + 回归线 + 置信区间，直接看到趋势
> 
> **什么时候用回归图？**
> 
> - 想知道两个变量是否有线性关系
> - 想预测一个变量对另一个变量的影响
> - 想量化两个变量的关系强度

#### **案例：使用 tips 数据集**

```python
tips = sns.load_dataset('tips')

# 基础回归图
plt.figure(figsize=(10, 6))
sns.regplot(data=tips, x='total_bill', y='tip')
plt.title('账单总额与小费的线性关系')
plt.xlabel('账单总额（美元）')
plt.ylabel('小费金额（美元）')
plt.show()
```

**📊 如何看懂回归图？**

1. **散点（蓝色点）**：
  - 每个点 = 一次用餐记录
  - 横坐标 = 账单总额
  - 纵坐标 = 小费金额
2. **回归线（蓝色直线）**：
  - 表示"最佳拟合"的线性关系
  - 斜率 = 账单每增加 1 美元，小费增加多少
  - 这条线使所有点到线的距离平方和最小
3. **置信区间（浅蓝色阴影）**：
  - 表示回归线的不确定性
  - 阴影越窄 = 回归越可靠
  - 阴影越宽 = 数据越分散，预测越不准

**💡 从这个图能看出什么？**

- ✅ **正相关关系**：回归线向右上方倾斜，说明账单越高，小费越多
- ✅ **线性关系明显**：点大致沿着回归线分布
- ✅ **小费约为账单的 15%**：从斜率可以估算（目测斜率约 0.15）
- ✅ **有一定分散**：点不是完全在线上，说明还有其他因素影响小费
- ✅ **没有明显异常值**：没有离群很远的点
- ✅ **关系稳定**：置信区间较窄，说明这个关系比较可靠

#### **参数说明**

### 线性模型图 (lmplot)

> **用途：** 在多个子图中展示回归关系，支持分面和分组
> 
> **lmplot vs regplot：**
> 
> - **regplot**：单个图表，简单直接
> - **lmplot**：可以创建多个子图（分面），功能更强大
> 
> **什么时候用 lmplot？**
> 
> - 需要对比不同组的回归关系

### 残差图 (residplot)

> **用途：** 检查回归模型的质量，诊断模型问题
> 
> **什么是残差？**
> 残差 = 实际值 - 预测值。如果回归模型很好，残差应该随机分布在0附近。
> 
> **什么是残差图？**
> 残差图显示每个数据点的残差，用来检查回归模型是否合适。
> 
> **为什么需要残差图？**
> 
> - 检查模型是否合适（线性 vs 非线性）
> - 发现异常值
> - 检查方差是否均匀（同方差性）
> - 验证回归假设

#### **案例：使用 mpg 数据集**

```python
# 残差图
plt.figure(figsize=(10, 6))
sns.residplot(data=mpg, x='weight', y='mpg', lowess=True, 
              scatter_kws={'alpha': 0.5}, line_kws={'color': 'red', 'linewidth': 2})
plt.title('回归残差图：重量 vs 油耗')
plt.xlabel('重量（磅）')
plt.ylabel('残差（实际值 - 预测值）')
plt.axhline(0, linestyle='--', color='gray', alpha=0.5)
plt.show()
```

**📊 如何看懂残差图？**

1. **横轴（X轴）**：自变量（重量）
2. **纵轴（Y轴）**：残差值
  - 正值 = 实际油耗高于预测（模型低估）
  - 负值 = 实际油耗低于预测（模型高估）
  - 0 = 预测完美
3. **灰色虚线**：y=0 的参考线
4. **红色曲线**：LOWESS 平滑线，显示残差的趋势

**💡 从这个图能看出什么？**

**好的残差图应该是：**

- ✅ 点随机分布在 y=0 附近
- ✅ 红色曲线接近水平线（y=0）
- ✅ 残差的分散程度均匀（左右一致）
- ✅ 没有明显的模式或趋势

**如果残差图显示：**

- ⚠️ **红色曲线呈U型或倒U型** → 应该用多项式回归（order=2）
- ⚠️ **残差呈喇叭形（右侧更分散）** → 方差不均匀，考虑对数变换
- ⚠️ **有明显的离群点** → 可能有异常数据
- ⚠️ **残差有明显趋势** → 线性模型不合适

**从这个例子看：**

- ✅ 红色曲线略微弯曲，但基本接近0
- ✅ 残差分布较均匀
- ✅ 没有明显的异常值
- ✅ 线性模型基本合适，但可能二次模型更好

#### **实用技巧：对比不同模型的残差**

```sql
# 2. 二次模型残差

axes[1].axhline(0, linestyle='--', color='gray', alpha=0.5)
axes[1].set_title('二次模型残差 (order=2)')
axes[1].set_ylabel('')

# 3. 三次模型残差
```

**💡 如何选择最佳模型？**

- ✅ 残差最随机、最接近0的模型最好
- ✅ 红色曲线最平的模型最好
- ⚠️ 但不要过拟合（order太高）

**🎯 实际应用场景：**

- 模型诊断：检查回归模型是否合适
- 异常值检测：发现数据中的异常点

### 聚类热力图 (clustermap)

> **用途：** 带层次聚类的热力图，自动对行和列进行分组
> 
> **什么是聚类热力图？**
> 在普通热力图的基础上，自动对相似的行和列进行聚类（分组），并重新排列，让相似的数据靠在一起。
> 
> **聚类热力图 vs 普通热力图：**
> 
> - **普通热力图**：按原始顺序显示
> - **聚类热力图**：按相似度重新排序，并显示树状图（dendrogram）
> 
> **什么时候用聚类热力图？**
> 
> - 想发现数据中的自然分组
> - 想找出相似的样本或特征
> - 数据量较大，需要自动分组

#### **案例：使用 iris 数据集**

```python
iris = sns.load_dataset('iris')

# 准备数据（标准化）
from sklearn.preprocessing import StandardScaler
iris_features = iris.drop('species', axis=1)
iris_scaled = StandardScaler().fit_transform(iris_features)
iris_scaled_df = pd.DataFrame(iris_scaled, columns=iris_features.columns)

# 聚类热力图
sns.clustermap(iris_scaled_df.T, cmap='vlag', center=0, 
               figsize=(10, 6), dendrogram_ratio=0.15)
plt.title('鸢尾花特征聚类热力图')
plt.show()
```

**📊 如何看懂聚类热力图？**

1. **树状图（dendrogram）**：
  - 顶部和左侧的"树"
  - 显示聚类的层次结构
  - 分支越短 = 越相似
  - 分支越长 = 差异越大
2. **热力图主体**：
  - 和普通热力图一样
  - 但行和列已经重新排序
3. **颜色条**：
  - 右侧显示颜色和数值的对应关系

**💡 从这个图能看出什么？**

- ✅ **特征分组**：petal_length 和 petal_width 聚在一起（相似）
- ✅ **样本分组**：150个样本自动分成几个组
- ✅ **模式发现**：能看到哪些样本在所有特征上都相似
- ✅ **异常值**：与其他样本差异很大的会单独成组

#### **案例：相关性矩阵聚类**

- ✅ **自动排序**：不需要手动调整顺序，算法自动找出最佳排列

### 配对图 (pairplot)

> **用途：** 展示数据集中所有变量两两之间的关系，一次性看到所有组合
> 
> **什么是配对图？**
> 配对图创建一个网格，显示数据集中每两个变量之间的关系。对角线显示单个变量的分布，非对角线显示两个变量的关系。
> 
> **什么时候用配对图？**
> 
> - 初步探索数据，了解变量之间的关系
> - 寻找相关性和模式
> - 发现异常值
> - 选择建模的特征


**📊 如何看懂配对图？**

  - 显示单个变量的分布（直方图或KDE）

3. **非对角线**：

  - 橙色 = versicolor

- ✅ **花瓣特征最有区分度**：petal_length 和 petal_width 的子图中，三种颜色分得最开

### 联合分布图 (jointplot)

> 
> **什么是联合分布图？**
> 联合分布图由三部分组成：
> 
> - 中心：两个变量的关系（散点图、密度图等）
> - 顶部：X变量的分布（直方图或密度图）
> - 右侧：Y变量的分布（直方图或密度图）
> 
> **什么时候用联合分布图？**
> 
> - 想同时看两个变量的关系和各自的分布
> - 想了解变量的边缘分布（marginal distribution）
> - 聚焦分析两个特定变量

#### **案例：使用 penguins 数据集**

```python

```

**📊 如何看懂联合分布图？**

1. **中心散点图**：

### 成对关系图 (PairGrid)

> **用途：** 更灵活的配对图，可自定义每个位置的图表类型
> 
> **什么是 PairGrid？**
> PairGrid 是 pairplot 的底层实现，提供了更高的灵活性：
> 
> - pairplot：快速创建，所有子图类型相同
> - PairGrid：完全自定义，可以让上三角、下三角、对角线显示不同类型的图表
> 
> **什么时候用 PairGrid？**
> 
> - 想要上三角和下三角显示不同类型的图表
> - 想要对角线显示特殊的分布图
> - 需要对每个位置进行精细控制
> - pairplot 的功能不够用时

#### **案例：使用 iris 数据集**

```python
iris = sns.load_dataset('iris')

g = sns.PairGrid(iris, hue='species', height=2.5)
g.map_upper(sns.scatterplot)
g.map_lower(sns.kdeplot)
g.map_diag(sns.histplot)
g.add_legend()
plt.suptitle('自定义配对图', y=1.02)
plt.show()
```

**📊 如何看懂 PairGrid？**

1. **整体布局**：

  - 对角线：单变量的分布（直方图）
  - 上三角：散点图显示两变量关系
  - 下三角：密度图显示两变量的联合分布
2. **上三角（散点图）**：
  - 每个点代表一个样本
  - 不同颜色 = 不同物种
  - 点的分布显示变量间的关系

  - 等高线显示数据密度

  - 线越密集 = 数据越集中
4. **对角线（直方图）**：
  - 显示单个变量的分布
  - 三种颜色堆叠显示
  - 能看到每个变量的范围和频数

**💡 从这个图能看出什么？**

- ✅ **上下三角互补**：上三角看具体点的分布，下三角看整体密度趋势

- ✅ **密度图更清晰**：能看到三个物种的"核心区域"在哪里
- ✅ **对角线看分布**：能快速判断每个变量的分布形状

```python
tips = sns.load_dataset('tips')
```

```python
def custom_plot(x, y, **kwargs):
    ax = plt.gca()
    ax.scatter(x, y, alpha=0.5, **kwargs)
    # 添加回归线
    z = np.polyfit(x, y, 1)
    p = np.poly1d(z)
    ax.plot(x, p(x), 'r--', linewidth=2)

g = sns.FacetGrid(tips, col='time', hue='sex', height=4)
g.map(custom_plot, 'total_bill', 'tip')
g.add_legend()
g.set_axis_labels('账单金额', '小费金额')
plt.show()
```

### 案例6：系外行星探索分析

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# 设置样式
sns.set_theme(style='ticks', palette='deep')
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

planets = sns.load_dataset('planets')
planets_clean = planets.dropna(subset=['mass', 'distance'])
```
