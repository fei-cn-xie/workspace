# 4. 智慧问诊 Agent

# 基本需求

> Agent 需要和用户进行**多轮对话来收集用户问诊的一些症状**。
> 
> 1. **一般的模糊回答**，比如用户说**自己不舒服**，就由 agent 进行追问。
> 2. 用户稍微说清楚了**一两个症状以后**，基于这一两个症状，去**neo4j**中找到对应的**所有病症**，然后拿到这些**病症对应的症状**，继续追问用户是否有如下的一些症状。
>   1. **HyDE**：假设性文档问答：由大模型去精确一下相关内容，自己提几个假设问题。
>   2. **HyDE 精确版：追问一两个精确症状，基于图关系检索，继续深入精确。**
> 3. 还要结合**长期记忆**，以及用户以前保存在 **postgresql **的**问诊记录**信息，以及**会话信息**，给用户展示最可能**出现的其他症状**，询问**是否具有**，如果不具有，再判断是否在相关疾病并发症内，如果都没有，有可能是**新的疾病**。
> 4. <u>**通过最多10轮的对话**</u>，基本确定出用户的疾病，以及相关症状，以及其他**疑似病**，然后询问用户是否**挂号**，**再挂号**。
> 5. 医生能看到的挂号信息就是基本80%确认的信息。
