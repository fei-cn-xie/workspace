# 本地安装

https://jupyter.org/install

```shell
# 安装
pip install jupyterlab

# 启动
jupyter lab
```

# 测试使用

## 指定workspace

启动 jupyter lab 的时候，进入指定文件夹，再cmd，启动 `jupyter lab`

这样，这个文件夹，就是当前的工作空间，以后打包这个文件夹进行分享即可
