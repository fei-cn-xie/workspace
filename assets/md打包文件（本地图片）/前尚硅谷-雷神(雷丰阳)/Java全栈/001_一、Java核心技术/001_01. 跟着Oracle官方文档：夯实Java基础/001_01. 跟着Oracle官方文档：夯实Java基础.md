# 官网路线

官网：https://docs.oracle.com/javase/tutorial/

> 1. **入门**
>   1. 了解Java历史、背景、工作机制
>   2. 熟悉基础概念：JDK、JRE、JVM，了解跨平台原理
>   3. 环境配置、编写HelloWorld、常见错误、详细解释
>   4. 扩展：计算机世界、位与字节、常见位运算

> 1. **Java核心语法**
>   1. 面向对象概念：对象、类、继承、接口、包
>   2. 基础语法：
>     - 变量、数据类型
>     - 数组
>     - 运算符
>     - 表达式、语句、代码块
>   3. 流程控制
>     - if, else, else if
>     - switch, case
>     - while, do-while
>     - for
>     - break, continue, return
>   4. 类与对象
>     - 类：声明、成员变量、方法、构造器、参数传递
>     - 对象：创建对象、使用对象
>     - 扩展：方法返回值、this关键字、理解类成员、初始化代码块
>     - 内部类：内部类、静态内部类、变量遮蔽、局部类
>     - 枚举类型
>   5. 接口与继承
>     - 接口：定义接口、实现接口、接口演变、默认实现
>     - 继承：多种继承方式、Override、多态性
>     - 扩展：super关键字、finall关键字、抽象类
>   6. Number和String
>     - Numbers类：包装类型、格式化输出、高阶运算
>     - Characters类**：**实用方法、序列转义
>     - Strings类：创建字符串、长度、字符串连接、类型转换、字符操作、比较、StringBuilder
>     - 自动拆装箱
>   7. 泛型
>     - 应用场景、泛型类型、原始类型、泛型方法、带限定的类型参数、多重限定
>     - 泛型、继承、子类型、类型推断、通配符、类型擦除
>   8. 包
>     - 创建包、使用包、包命名格式、名称歧义问题
> 
>   扩展：lambda表达式

> 1. **数据容器 - 集合类**
>   1. 集合类体系
>   2. Collection、Set、List、Queue、Deque、Map
>   3. 对象排序、接口实现、基本数据结构原理

> 1. **Java进阶使用**
>   1. 异常
>     - 三种异常机制、try-catch-finally、try-with-resources
>     - 异常抛出、异常链、堆栈信息、异常的优点
>   2. IO
>     - 基本IO：字节流、字符流、Buffer流、命令行IO、数据流、对象流
>     - 文件IO：路径、路径操作、文件操作、检查、删除、复制、移动、元信息
>     - 扩展操作：读/写/创建、随机访问、创建链接、遍历文件树、变化监听、
>   3. 并发
>     - 概念：进程、线程
>     - 线程：创建、启动、暂停、休眠、中断、插队
>     - 同步：内存并发错误、synchornized方法、内置锁、原子访问
>     - 锁活性：死锁、活锁、饥饿
>     - 受保护块、不可变对象、定义不可变对象策略
>     - 高阶并发：Lock对象、线程池、并发集合、原子变量、并发随机数、
>   4. 网络
>     - 基础：TCP、UDP、端口
>     - URL：创建、解析、读取数据
>     - Socket：工作原理、读写Socket数据、Socket服务端小程序
>     - Datagram：数据报、客户端与服务端、数据广播
>     - NetworkInterface：网络接口是什么、查询/列举网络接口、参数
>   5. 反射
>     - 类：获取类对象、检查修饰符和类型、发现类成员
>     - 成员：获取属性、修饰符、获取&设置值、获取方法信息、调用方法、构造器、创建实例
>     - 反射获取数组&枚举
>   6. 工具类
>     - 时间日期API
>     - 系统函数
>     - 正则表达式
