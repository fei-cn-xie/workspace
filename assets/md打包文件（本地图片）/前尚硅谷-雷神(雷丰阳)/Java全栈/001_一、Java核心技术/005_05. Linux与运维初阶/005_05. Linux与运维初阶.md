### 配置yum国内源

> yum 是 centos 中在线安装软件的一种方法。默认会从 redhat 官方下载软件。但是由于centos停止维护，所以官方源已经关闭了。我们可以使用国内源；（就像是**google应用商店**用不了，但是其他**国内**可以用）

```shell
# 1. 备份
sudo cp /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.bak

# 2. 配置
sudo wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo

# 3. 清缓存
sudo yum clean all
sudo yum makecache

# 4. 验证
sudo yum repolist
sudo yum install -y vim
```
