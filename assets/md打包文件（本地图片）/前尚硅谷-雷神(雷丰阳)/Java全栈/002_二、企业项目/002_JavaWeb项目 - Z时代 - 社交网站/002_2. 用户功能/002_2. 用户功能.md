# 登录

## 基本登录逻辑

- 用户提交账号密码
- UserService将密码md5后，交给UserDao
- UserDao去数据库按照账号密码查询对应记录
- 查到记录：则登录成功；把用户放到session中
- 没有查到记录：则登录失败，回到登录页，提示账号密码错误
