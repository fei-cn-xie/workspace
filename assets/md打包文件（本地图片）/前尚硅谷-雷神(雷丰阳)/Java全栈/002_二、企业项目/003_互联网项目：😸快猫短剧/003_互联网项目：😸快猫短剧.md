# 项目背景

**短剧本身与网文同脉同源**，旨在为人们提供一个低压力、高刺激感的幻想世界，用来消解更复杂的现实社会压力。这些网络小说剧情被真人演绎出来以后颇受原著党喜爱，能够吸引诸多受众。

短剧：通常采用单集时长**1~3分钟的系列剧**、**集数在100集内**的连续剧、**周播剧**等多种形态，具有**篇幅短小**、**内容精炼**、情节紧凑等特点。可以说短剧有着明确的“双短”的特点，**剧集短、时长短**，核心逻辑就是“**爽**”。

该原型作品主要内容包括：首页、剧场中心、短剧搜索、热搜排行榜、我的追剧、播放历史、福利中心、个人中心（我的消息、我的点赞、我的评论、看剧偏好、设置）、登录注册等，已覆盖短剧APP主流业务功能。

## 盈利模式

### 广告收入模式

**展示广告**

- **前贴片广告**：每集开始前播放15-30秒广告
- **中插广告**：长集数中间插播广告
- **暂停广告**：用户暂停时显示静态广告
- **开屏广告**：App启动时的全屏广告

**信息流广告**

- **推荐页广告**：在剧集推荐列表中插入原生广告
- **分类页广告**：各分类页面的横幅和卡片广告
- **搜索广告**：搜索结果页的推广内容

**互动广告**

- **激励视频广告**：观看广告解锁免费集数
- **试玩广告**：游戏类广告的互动体验
- **品牌植入**：剧集内容中的品牌露出

### 单集付费模式（海外）

> 特别火爆的短剧，可以仅发布短剧的小程序页。

**付费策略**

- **热门剧集**：新上线热门剧集前几集免费，后续集数付费
- **精品内容**：高制作成本剧集采用单集付费模式
- **提前看**：会员可提前解锁，非会员付费观看

**定价策略**

- **标准定价**：单集1-3元，根据内容质量和热度调整
- **打包优惠**：整部剧集打包购买享受折扣
- **限时促销**：新剧上线期间的优惠定价

海外短剧平台：https://www.reelshort.com/

### 增值收入

**虚拟商品**

- **礼品打赏**：用户可向喜欢的剧集和演员打赏虚拟礼品
- **个性化装扮**：头像框、昵称特效等个性化元素
- **专属表情包**：剧集相关的表情包和贴纸

**衍生服务**

- **周边商品**：热门剧集的实体周边销售（服饰、首饰、手办等）
- **线下活动**：见面会、首映礼等活动门票
- **IP授权**：剧集IP的商业化授权收入

# 项目管理

## 开发排期

**项目分为两阶段开发**：

1. 阶段1：**开发后台管理系统**
  1. 熟悉ruoyi脚手架，以及基本的CRUD接口（**用户**、**部门**、**角色**、**权限 - CRUD**）
2. 阶段2：**开发短剧分布式系统**
  1. 开发**内容管理微服务**：**短剧管理**、**短剧发布、剧集、演员、标签模块**
  2. 开发**短剧微服务**：首页短剧、短剧介绍、短剧剧集、短剧播放、进度管理
    1. **缓存解决方案**：Redis：分布式缓存 + 位图
  3. 开发**评论微服务**：评论发布、评论回复、AI评论审核
    1. **AI解决方案**：Spring AI：AI 违禁词识别
  4. 开发**检索微服务**：短剧检索、热搜推荐
    1. **检索解决方案**：ElasticSearch：数据建模与检索
  5. 开发**VIP会员服务**：**包月/包周**会员、单集解锁、全局解锁
    1. **订单解决方案**：微信/支付宝支付、订单关单、消息队列
  6. 开发**数据大屏模块**：订单统计、用户量、播放量
